## fuzzy_algorithm property

The fuzzy search algorithm. The currently available fuzzy search algorithms are [`SimilarityLevel`](/search/python-net/groupdocs.search.options/similaritylevel/) and [`TableDiscreteFunction`](/search/python-net/groupdocs.search.options/tablediscretefunction/). The default value is an instance of [`SimilarityLevel`](/search/python-net/groupdocs.search.options/similaritylevel/) with a similarity level value of 0.5.

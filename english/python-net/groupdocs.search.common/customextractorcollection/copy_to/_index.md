## copy_to {#array-array_index}

Copies the elements of the collection to an array, starting at a particular array index.

```python
def copy_to(self, array, array_index):
    ...
```

| Parameter | Type | Description |
| :- | :- | :- |
| array | `list[IFieldExtractor]` | The one-dimensional array that is the destination of the elements copied from the collection. The array must have zero-based indexing. |
| array_index | `int` | The zero-based index in array at which copying begins. |

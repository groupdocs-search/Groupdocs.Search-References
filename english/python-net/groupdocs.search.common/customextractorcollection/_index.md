## CustomExtractorCollection class

Represents a collection of custom extractors. If the collection contains an extractor for a file extension that is also handled by built‑in extractors, the custom extractor is used instead of the built‑in one.

Learn more:

- [Custom text extractors](https://docs.groupdocs.com/search/python-net/custom-text-extractors/)

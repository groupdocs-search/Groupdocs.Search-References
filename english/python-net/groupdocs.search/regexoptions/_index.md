## RegexOptions class

The RegexOptions type exposes the following members:

### Fields
| Field | Description |
| :- | :- |
| [NONE](/search/python-net/groupdocs.search/regexoptions/none/) | Specifies that no options are set. |
| [IGNORE_CASE](/search/python-net/groupdocs.search/regexoptions/ignore_case/) | Specifies case-insensitive matching. |
| [MULTILINE](/search/python-net/groupdocs.search/regexoptions/multiline/) | Multiline mode: ^ and $ match at the beginning and end of any line. |
| [EXPLICIT_CAPTURE](/search/python-net/groupdocs.search/regexoptions/explicit_capture/) | Specifies that the only valid captures are explicitly named or numbered groups. |
| [COMPILED](/search/python-net/groupdocs.search/regexoptions/compiled/) | Specifies that the regular expression is compiled instead of interpreted. |
| [SINGLELINE](/search/python-net/groupdocs.search/regexoptions/singleline/) | Single-line mode: the dot (.) matches every character, \n included. |
| [IGNORE_PATTERN_WHITESPACE](/search/python-net/groupdocs.search/regexoptions/ignore_pattern_whitespace/) | Eliminates unescaped white space from the pattern and enables comments marked with #. |
| [RIGHT_TO_LEFT](/search/python-net/groupdocs.search/regexoptions/right_to_left/) | Specifies that the search runs from right to left. |
| [ECMA_SCRIPT](/search/python-net/groupdocs.search/regexoptions/ecma_script/) | Enables ECMAScript-compliant behavior; combines only with IgnoreCase, Multiline and Compiled. |
| [CULTURE_INVARIANT](/search/python-net/groupdocs.search/regexoptions/culture_invariant/) | Specifies that cultural differences in language are ignored. |
| [NON_BACKTRACKING](/search/python-net/groupdocs.search/regexoptions/non_backtracking/) | Matches without backtracking, in time linear in the length of the input. |

该命名空间提供用于对不同格式文档中的文本数据进行索引和搜索的类。此命名空间中的主要类有：

## 类

| 类 | 描述 |
| --- | --- |
| [ExtractionHost](./extractionhost) | 表示用于在单独进程中从文档提取数据的服务。 |
| [Extractor](./extractor) | 表示用于从文档进行预先数据提取，以分离后续快速索引阶段的工具。 |
| [Index](./index) | 表示用于索引文档并在其上搜索的主类。 |
| [IndexRepository](./indexrepository) | 表示用于组合多个索引并对其执行通用操作的容器。 |
| [IndexSettings](./indexsettings) | 表示允许自定义索引操作的索引设置。 |
| [IndexUpdater](./indexupdater) | 表示索引更新器。此类在旧版本的索引中执行文档重新索引。 |
| [License](./license) | 提供应用许可证的方法。 |
| [Metered](./metered) | 提供允许使用计量许可证激活产品并检索已处理 MB 数量的方法。了解有关计量许可证的更多信息，请点击[此处](https://purchase.groupdocs.com/faqs/licensing/metered)。 |
| [SearchQuery](./searchquery) | 表示以对象形式的搜索查询。 |

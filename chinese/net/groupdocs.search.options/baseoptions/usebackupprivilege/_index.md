## BaseOptions.UseBackupPrivilege property

获取或设置一个值，指示进程是否应使用 SeBackupPrivilege 和 FILE_FLAG_BACKUP_SEMANTICS 来访问文件和目录。默认值为 `false`。

```csharp
public bool UseBackupPrivilege { get; set; }
```

### Property Value

`true` 表示使用 SeBackupPrivilege 和 FILE_FLAG_BACKUP_SEMANTICS 启用特权访问；否则为 `false`。

### 备注

启用后，允许进程绕过文件和目录的安全检查，允许访问通常受 ACL 限制的受保护资源——前提是进程拥有适当的特权。此功能仅在 Windows 操作系统上受支持。在非 Windows 平台上，启用此属性无效。请注意，这需要进程以管理员权限运行。使用时请谨慎，因为它可能允许访问敏感的系统文件和用户数据。

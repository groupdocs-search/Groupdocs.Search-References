## FileType.ASF field

Advanced Systems Format（ASF）是一种主要用于存储和传输媒体流的数字多媒体容器。Microsoft Windows Media Video（WMV）是压缩视频格式，Microsoft Windows Media Audio（WMA）是压缩音频格式，并且在 Microsoft 开发的 ASF 容器中包含额外的元数据。了解更多关于此文件格式的信息，请点击[here](https://wiki.fileformat.com/video/wmv/)。

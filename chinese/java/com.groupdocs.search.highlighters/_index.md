该包提供用于在文本中突出显示搜索结果的高亮器。



## 类

| 类 | 描述 |
| --- | --- |
| [DocumentHighlighter](../com.groupdocs.search.highlighters/documenthighlighter) | 表示在整个文档文本中突出显示搜索结果的搜索结果高亮器。 |
| [FragmentHighlighter](../com.groupdocs.search.highlighters/fragmenthighlighter) | 表示在文本片段中突出显示搜索结果的搜索结果高亮器。 |
| [Highlighter](../com.groupdocs.search.highlighters/highlighter) | 表示搜索结果高亮器的基类。 |

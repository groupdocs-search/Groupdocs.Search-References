该命名空间提供搜索网络中的搜索结果类。



## 类

| 类 | 描述 |
| --- | --- |
| [NetworkDocumentInfo](../com.groupdocs.search.scaling.results/networkdocumentinfo) | 表示搜索网络中已索引文档的描述符。 |
| [NetworkFoundDocument](../com.groupdocs.search.scaling.results/networkfounddocument) | 表示搜索网络中找到的文档。 |
| [NetworkImageSearchResult](../com.groupdocs.search.scaling.results/networkimagesearchresult) | 表示匹配搜索图像的图像搜索结果。 |
| [NetworkImageSearchToken](../com.groupdocs.search.scaling.results/networkimagesearchtoken) | 表示网络块图像搜索（按页搜索）继续的令牌。 |
| [NetworkSearchResult](../com.groupdocs.search.scaling.results/networksearchresult) | 表示匹配搜索查询的搜索结果。 |
| [NetworkSearchToken](../com.groupdocs.search.scaling.results/networksearchtoken) | 表示网络块搜索（按页搜索）继续的令牌。 |

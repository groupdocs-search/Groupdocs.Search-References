## Klasser

| Klass | Beskrivning |
| --- | --- |
| [DocumentHighlighter](../com.groupdocs.search.highlighters/documenthighlighter) | Representerar en sökresultatmarkerare som markerar sökresultat i hela dokumenttexten. |
| [FragmentHighlighter](../com.groupdocs.search.highlighters/fragmenthighlighter) | Representerar en sökresultatmarkerare som markerar sökresultat i textfragment. |
| [Highlighter](../com.groupdocs.search.highlighters/highlighter) | Representerar basklassen för en sökresultatmarkerare. |

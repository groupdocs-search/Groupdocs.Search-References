## BaseOptions.UseRawTextExtraction property

Hämtar eller anger ett värde som indikerar om råläge används för textutvinning om möjligt. Standardvärdet är `false`. Råläge kan avsevärt öka indexeringshastigheten, men normalt läge förbättrar formateringen av den extraherade texten.

```csharp
public bool UseRawTextExtraction { get; set; }
```

### Property Value

Ett värde som indikerar om råläge används för textutvinning om möjligt.

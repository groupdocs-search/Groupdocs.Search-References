## BaseOptions.Encoding property

Hämtar eller anger den kodning som används för att extrahera text från textdokument. Standardvärdet är `null`, vilket betyder att standardkodningen UTF-8 används. Om AutoDetectEncoding är `true` används detta värde som standardkodning.

```csharp
public string Encoding { get; set; }
```

### Property Value

Kodningen som används för att extrahera text från textdokument.

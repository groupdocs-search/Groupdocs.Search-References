## BaseOptions.UseBackupPrivilege property

Hämtar eller anger ett värde som indikerar om processen ska använda SeBackupPrivilege och FILE_FLAG_BACKUP_SEMANTICS för att komma åt filer och kataloger. Standardvärdet är `false`.

```csharp
public bool UseBackupPrivilege { get; set; }
```

### Property Value

`true` för att aktivera privilegierad åtkomst med SeBackupPrivilege och FILE_FLAG_BACKUP_SEMANTICS; annars `false`.

### Anmärkningar

När den är aktiverad tillåter detta processen att kringgå säkerhetskontroller för filer och kataloger, vilket ger åtkomst till skyddade resurser som vanligtvis begränsas av ACL‑regler — så länge processen har rätt behörigheter. Denna funktion stöds endast på Windows‑operativsystem. På icke‑Windows‑plattformar har aktivering av denna egenskap ingen effekt. Observera att detta kräver att processen körs med administratörsrättigheter. Använd med försiktighet, eftersom det kan ge åtkomst till känsliga systemfiler och användardata.

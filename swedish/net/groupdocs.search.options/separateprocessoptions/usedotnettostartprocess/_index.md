## SeparateProcessOptions.UseDotnetToStartProcess property

Hämtar eller anger flaggan för att använda `dotnet` för att starta processen. Standardvärdet är `true`. Sätt värdet till `false` om du vill starta en fristående applikation. Observera att `dotnet` aldrig används för att starta på den gamla .NET Framework.

public bool UseDotnetToStartProcess { get; set; }

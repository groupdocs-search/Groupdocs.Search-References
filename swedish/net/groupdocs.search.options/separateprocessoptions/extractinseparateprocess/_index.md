## SeparateProcessOptions.ExtractInSeparateProcess property

Hämtar eller anger ett värde som indikerar om en separat process används för att extrahera data från dokument. Standardvärdet är `false`. När detta alternativ är aktiverat utförs dataextraktion i en separat process med endast en tråd. Det angivna antalet trådar ignoreras vid extraktion i en separat process.

```csharp
public bool ExtractInSeparateProcess { get; set; }
```

### Property Value

Ett värde som indikerar om en separat process används för att extrahera data från dokument.

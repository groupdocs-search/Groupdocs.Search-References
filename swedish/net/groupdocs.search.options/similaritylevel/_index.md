## SimilarityLevel class

Representerar en algoritm för fuzzy-sökning som specificerar likhetsnivån. Algoritmen för likhetsnivå beräknar det maximala antalet fel för ett ord som omvänt proportionellt mot ordets längd.

```csharp
public class SimilarityLevel : FuzzyAlgorithm
```

### Exempel

Exemplet visar ett typiskt användningssätt av klassen.

```csharp
string indexFolder = @"c:\MyIndex\";
string documentsFolder = @"c:\MyDocuments\";
string query = "Einstein";

Index index = new Index(indexFolder); // Creating an index in the specified folder
index.Add(documentsFolder); // Indexing documents from the specified folder

SearchOptions options = new SearchOptions();
options.FuzzySearch.Enabled = true; // Enabling the fuzzy search
options.FuzzySearch.FuzzyAlgorithm = new SimilarityLevel(0.8); // Creating the fuzzy search algorithm
// Denna funktion anger 0 som maximalt antal fel för ord med 1 till 4 tecken.
// Den anger 1 som maximalt antal fel för ord med 5 till 9 tecken.
// Den anger 2 som maximalt antal fel för ord med 10 till 14 tecken. Och så vidare.

SearchResult result = index.Search(query, options); // Search in index
```

## Index.GetIndexedDocuments method

Hämtar en array med alla indexerade dokument.


### Returvärde

### Exempel

Exemplet visar hur man hämtar en lista med indexerade dokument från ett index.

```csharp
string indexFolder = @"c:\MyIndex\";
string documentsFolder = @"c:\MyDocuments\";
 
// Skapar ett index i den angivna mappen
Index index = new Index(indexFolder);
 
// Indexerar dokument från den angivna mappen
index.Add(documentsFolder);
 
// Hämtar lista med indexerade dokument
DocumentInfo[] documents = index.GetIndexedDocuments();
```

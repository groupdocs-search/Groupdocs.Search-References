## Delete(string[], UpdateOptions) {#delete_1}

Tar bort indexerade filer eller mappar från indexet. Uppdaterar sedan indexet utan de borttagna sökvägarna. Observera att ett enskilt dokument inte kan tas bort från indexet om det lades till som en del av en mapp.

```csharp
public DeleteResult Delete(string[] paths, UpdateOptions options)
```

| Parameter | Typ | Beskrivning |
| --- | --- | --- |
| paths | String[] | Sökvägarna till filer eller mappar som ska raderas. |
| options | UpdateOptions | Uppdateringsalternativen. |

### Returvärde

Ett objekt som beskriver resultatet av att radera filer eller mappar från indexet.

### Exempel

Exemplet visar hur man tar bort indexerade sökvägar från ett index.

```csharp
string indexFolder = @"c:\MyIndex\";
string documentsFolder1 = @"c:\MyDocuments\";
string documentsFolder2 = @"c:\MyDocuments2\";

// Skapar ett index i den angivna mappen
Index index = new Index(indexFolder);

// Indexerar dokument från de angivna mapparna
index.Add(documentsFolder1);
index.Add(documentsFolder2);

// Hämtar indexerade sökvägar från indexet
string[] indexedPaths1 = index.GetIndexedPaths();

// Skriver ut indexerade sökvägar till konsolen
Console.WriteLine("Indexed paths:");
foreach (string path in indexedPaths1)
{
    Console.WriteLine("\t" + path);
}

// Tar bort indexväg från indexet
DeleteResult deleteResult = index.Delete(new string[] { documentsFolder1 }, new UpdateOptions());

// Hämtar indexerade sökvägar efter radering
string[] indexedPaths2 = index.GetIndexedPaths();
Console.WriteLine("\nDeleted paths: " + deleteResult.SuccessCount);

Console.WriteLine("\nIndexed paths:");
foreach (string path in indexedPaths2)
{
    Console.WriteLine("\t" + path);
}
```

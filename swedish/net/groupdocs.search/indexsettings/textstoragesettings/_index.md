## IndexSettings.TextStorageSettings property

Hämtar eller anger inställningarna för textlagring. Standardvärdet är `null`, vilket betyder att dokumenttexter inte lagras.

```csharp
public TextStorageSettings TextStorageSettings { get; set; }
```

### Property Value

Textlagringsinställningarna.

### Exempel

Exemplet visar hur man anger textlagringsinställningarna.

```csharp
string indexFolder = @"c:\MyIndex\";
string documentsFolder = @"c:\MyDocuments\";

// Skapar en instans av indexinställningar
IndexSettings settings = new IndexSettings();
settings.TextStorageSettings = new TextStorageSettings(Compression.High); // Setting high compression level for the index text storage

// Skapar ett index i den angivna mappen
Index index = new Index(indexFolder, settings);

// Indexerar dokument
index.Add(documentsFolder);

// Sökning
SearchResult result = index.Search("Einstein");
```

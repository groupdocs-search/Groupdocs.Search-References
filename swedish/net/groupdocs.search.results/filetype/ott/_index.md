## FileType.OTT field

Filer med OTT‑tillägg representerar mall‑dokument som genereras av program i enlighet med OASIS OpenDocument‑standardformatet. Dessa skapas med ordbehandlingsprogram såsom den kostnadsfria OpenOffice Writer och kan innehålla inställningar som kan användas för att generera nya dokument från dessa mallfiler. Läs mer om detta filformat [här](https://wiki.fileformat.com/word-processing/ott/).

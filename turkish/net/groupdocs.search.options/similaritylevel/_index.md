## SimilarityLevel class

Benzerlik seviyesini belirten bir bulanık arama algoritmasını temsil eder. Benzerlik seviyesi algoritması, bir kelimenin maksimum hata sayısını kelime uzunluğunun ters orantılı olarak hesaplar.

### Örnekler

Bu örnek, sınıfın tipik bir kullanımını gösterir.

```csharp
string indexFolder = @"c:\MyIndex\";
string documentsFolder = @"c:\MyDocuments\";
string query = "Einstein";

Index index = new Index(indexFolder); // Creating an index in the specified folder
index.Add(documentsFolder); // Indexing documents from the specified folder

SearchOptions options = new SearchOptions();
options.FuzzySearch.Enabled = true; // Enabling the fuzzy search
options.FuzzySearch.FuzzyAlgorithm = new SimilarityLevel(0.8); // Creating the fuzzy search algorithm
// Bu işlev, 1 ila 4 karakter uzunluğundaki kelimeler için maksimum hata sayısını 0 olarak belirler.
// 5 ila 9 karakter uzunluğundaki kelimeler için maksimum hata sayısını 1 olarak belirler.
// 10 ila 14 karakter uzunluğundaki kelimeler için maksimum hata sayısını 2 olarak belirler. Ve benzeri.

SearchResult result = index.Search(query, options); // Search in index
```

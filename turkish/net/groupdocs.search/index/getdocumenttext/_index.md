## GetDocumentText(DocumentInfo, OutputAdapter) {#getdocumenttext}

İndekslenmiş bir belgenin metnini oluşturur ve bir çıktı adaptörü aracılığıyla iletir.

```csharp
public void GetDocumentText(DocumentInfo documentInfo, OutputAdapter adapter)
```

| Parametre | Tür | Açıklama |
| --- | --- | --- |
| documentInfo | DocumentInfo | Dizine eklenmiş belge bilgisi. |
| adapter | OutputAdapter | Çıktı adaptörü. |

### Örnekler

Örnek, bir dizinden dizine eklenmiş belgenin metnini nasıl alacağınızı gösterir.

```csharp
string indexFolder = @"c:\MyIndex\";
string documentsFolder = @"c:\MyDocuments\";
 
// Belirtilen klasörde bir dizin oluşturuluyor
Index index = new Index(indexFolder);
 
// Belirtilen klasörden belgeler indeksleniyor
index.Add(documentsFolder);
 
// İndekslenmiş belgelerin listesini alma
DocumentInfo[] documents = index.GetIndexedDocuments();
 
// Belge metni alma
if (documents.Length > 0)
{
    FileOutputAdapter outputAdapter = new FileOutputAdapter(@"C:\Text.html");
    index.GetDocumentText(documents[0], outputAdapter);
}
```

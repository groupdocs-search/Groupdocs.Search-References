## Delete(string[], UpdateOptions) {#delete_1}

İndeksten indekslenmiş dosya veya klasörleri siler. Ardından silinen yollar olmadan indeksi günceller. Bir belge, bir klasörün parçası olarak indekse eklenmişse, tek başına indeksden silinemez.

```csharp
public DeleteResult Delete(string[] paths, UpdateOptions options)
```

| Parametre | Tür | Açıklama |
| --- | --- | --- |
| yollar | String[] | Silinecek dosya veya klasörlerin yolları. |
| seçenekler | UpdateOptions | Güncelleme seçenekleri. |

### Dönüş Değeri

İndeksten dosya veya klasörlerin silinmesinin sonucunu tanımlayan bir nesne.

### Örnekler

Örnek, bir indeks'ten indekslenmiş yolların nasıl silineceğini gösterir.

```csharp
string indexFolder = @"c:\MyIndex\";
string documentsFolder1 = @"c:\MyDocuments\";
string documentsFolder2 = @"c:\MyDocuments2\";

// Belirtilen klasörde bir dizin oluşturuluyor
Index index = new Index(indexFolder);

// Belirtilen klasörlerden belgeleri indeksleme
index.Add(documentsFolder1);
index.Add(documentsFolder2);

// İndeksten indekslenmiş yolları alma
string[] indexedPaths1 = index.GetIndexedPaths();

// İndekslenmiş yolları konsola yazma
Console.WriteLine("Indexed paths:");
foreach (string path in indexedPaths1)
{
    Console.WriteLine("\t" + path);
}

// İndeksten indeks yolu silme
DeleteResult deleteResult = index.Delete(new string[] { documentsFolder1 }, new UpdateOptions());

// Silme işleminden sonra indekslenmiş yolları alma
string[] indexedPaths2 = index.GetIndexedPaths();
Console.WriteLine("\nDeleted paths: " + deleteResult.SuccessCount);

Console.WriteLine("\nIndexed paths:");
foreach (string path in indexedPaths2)
{
    Console.WriteLine("\t" + path);
}
```

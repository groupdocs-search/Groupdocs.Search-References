このパッケージは、さまざまな辞書のクラスを提供します。



## クラス

| クラス | 説明 |
| --- | --- |
| [AliasReplacementPair](../com.groupdocs.search.dictionaries/aliasreplacementpair) | エイリアス/置換ペアを表します。 |
| [CharacterReplacementPair](../com.groupdocs.search.dictionaries/characterreplacementpair) | 文字/置換ペアを表します。 |
| [DictionaryRepository](../com.groupdocs.search.dictionaries/dictionaryrepository) | インデックス内のすべての辞書のリポジトリを表します。 |
| [EnglishWordFormsProvider](../com.groupdocs.search.dictionaries/englishwordformsprovider) | 英語の語形提供者を表します。 |

## インターフェイス

| インターフェイス | 説明 |
| --- | --- |
| [AliasDictionary](../com.groupdocs.search.dictionaries/aliasdictionary) | エイリアス辞書のインターフェイスを定義します。 |
| [Alphabet](../com.groupdocs.search.dictionaries/alphabet) | インデックス作成時に文字種を検出するために使用される文字辞書のインターフェイスを定義します。 |
| [CharacterReplacementDictionary](../com.groupdocs.search.dictionaries/characterreplacementdictionary) | インデックス作成プロセスで使用される文字置換辞書のインターフェイスを定義します。 |
| [DictionaryBase](../com.groupdocs.search.dictionaries/dictionarybase) | 辞書のインターフェイスを定義します。 |
| [HomophoneDictionary](../com.groupdocs.search.dictionaries/homophonedictionary) | 異形同音語辞書のインターフェイスを定義します。 |
| [IWordFormsProvider](../com.groupdocs.search.dictionaries/iwordformsprovider) | 単語形態提供者のインターフェイスを定義します。 |
| [PasswordDictionary](../com.groupdocs.search.dictionaries/passworddictionary) | 文書パスワード辞書のインターフェイスを定義します。 |
| [SpellingCorrector](../com.groupdocs.search.dictionaries/spellingcorrector) | クエリ内の用語のスペル補正機能のインターフェイスを定義します。 |
| [StopWordDictionary](../com.groupdocs.search.dictionaries/stopworddictionary) | ストップワード辞書のインターフェイスを定義します。 |
| [SynonymDictionary](../com.groupdocs.search.dictionaries/synonymdictionary) | 同義語辞書のインターフェイスを定義します。 |

## 列挙型

| 列挙型 | 説明 |
| --- | --- |
| [CharacterType](../com.groupdocs.search.dictionaries/charactertype) | インデックス方法に応じた文字のタイプを表します。 |
| [DictionaryType](../com.groupdocs.search.dictionaries/dictionarytype) | 辞書のタイプを表します。 |

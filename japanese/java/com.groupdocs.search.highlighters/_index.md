このパッケージは、テキスト内の検索結果をハイライト表示するためのハイライターを提供します。



## クラス

| クラス | 説明 |
| --- | --- |
| [DocumentHighlighter](../com.groupdocs.search.highlighters/documenthighlighter) | 文書全体のテキスト内で検索結果をハイライトする検索結果ハイライターを表します。 |
| [FragmentHighlighter](../com.groupdocs.search.highlighters/fragmenthighlighter) | テキストフラグメント内で検索結果をハイライトする検索結果ハイライターを表します。 |
| [Highlighter](../com.groupdocs.search.highlighters/highlighter) | 検索結果ハイライターの基底クラスを表します。 |

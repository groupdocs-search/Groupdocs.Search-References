このパッケージは、検索結果クラスを提供します。



## クラス

| クラス | 説明 |
| --- | --- |
| [DeleteResult](../com.groupdocs.search.results/deleteresult) | インデックスからインデックス化されたファイルまたはフォルダーを削除する操作の結果を表します。 |
| [DocumentInfo](../com.groupdocs.search.results/documentinfo) | インデックスされたドキュメントの記述子を表します。 |
| [FileType](../com.groupdocs.search.results/filetype) | ファイルタイプを表します。 |
| [FormatFamily](../com.groupdocs.search.results/formatfamily) | いくつかの類似したフォーマットを統合するフォーマットファミリーを指定します。 |
| [FoundDocument](../com.groupdocs.search.results/founddocument) | 見つかったドキュメントを表します。 |
| [FoundDocumentField](../com.groupdocs.search.results/founddocumentfield) | 見つかったドキュメントフィールドを表します。 |
| [FoundImageFrame](../com.groupdocs.search.results/foundimageframe) | 見つかった画像フレームを表します。 |
| [ImageSearchResult](../com.groupdocs.search.results/imagesearchresult) | 逆画像検索の結果を表します。 |
| [PathDeleteResult](../com.groupdocs.search.results/pathdeleteresult) | インデックスからインデックスされたファイルまたはフォルダーを削除する操作の結果を表します。 |
| [SearchResult](../com.groupdocs.search.results/searchresult) | 検索クエリに一致する検索結果を表します。 |

この名前空間は、スケーリング機能のクラスを提供します。



## クラス

| クラス | 説明 |
| --- | --- |
| [Indexer](../com.groupdocs.search.scaling/indexer) | 検索ネットワークのシャード間でインデックスされたドキュメントの配布を管理するサービスを表します。 |
| [SearchNetworkNode](../com.groupdocs.search.scaling/searchnetworknode) | 抽出器、インデクサ、検索者、シャードなどのサービスを含むことができる検索ネットワークノードを表します。 |
| [Searcher](../com.groupdocs.search.scaling/searcher) | 検索ネットワークのシャードへの検索クエリを管理するサービスを表します。 |

## 列挙型

| 列挙型 | 説明 |
| --- | --- |
| [SearchNetworkStatus](../com.groupdocs.search.scaling/searchnetworkstatus) | 検索ネットワークのステータスを指定します。 |

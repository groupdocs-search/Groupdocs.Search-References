この名前空間は、検索ネットワーク内の検索結果クラスを提供します。



## クラス

| クラス | 説明 |
| --- | --- |
| [NetworkDocumentInfo](../com.groupdocs.search.scaling.results/networkdocumentinfo) | 検索ネットワーク内のインデックス化されたドキュメントの記述子を表します。 |
| [NetworkFoundDocument](../com.groupdocs.search.scaling.results/networkfounddocument) | 検索ネットワーク内で見つかったドキュメントを表します。 |
| [NetworkImageSearchResult](../com.groupdocs.search.scaling.results/networkimagesearchresult) | 検索画像に一致する画像検索結果を表します。 |
| [NetworkImageSearchToken](../com.groupdocs.search.scaling.results/networkimagesearchtoken) | ページ単位の検索（search by pages）によるネットワークチャンク画像検索の継続用トークンを表します。 |
| [NetworkSearchResult](../com.groupdocs.search.scaling.results/networksearchresult) | 検索クエリに一致する検索結果を表します。 |
| [NetworkSearchToken](../com.groupdocs.search.scaling.results/networksearchtoken) | ページ単位の検索（search by pages）によるネットワークチャンク検索の継続用トークンを表します。 |

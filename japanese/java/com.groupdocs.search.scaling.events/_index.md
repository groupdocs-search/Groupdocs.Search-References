この名前空間は、検索ネットワーク内のイベント引数クラスを提供します。



## クラス

| クラス | 説明 |
| --- | --- |
| [DataExtractedEventArgs](../com.groupdocs.search.scaling.events/dataextractedeventargs) | ドキュメントのデータ抽出が完了したイベントの引数を表します。 |
| [DocumentDeletedEventArgs](../com.groupdocs.search.scaling.events/documentdeletedeventargs) | ドキュメントの削除が完了したイベントの引数を表します。 |
| [DocumentIndexedEventArgs](../com.groupdocs.search.scaling.events/documentindexedeventargs) | ドキュメントのインデックス作成が完了したイベントの引数を表します。 |
| [ErrorOccurredEventArgs](../com.groupdocs.search.scaling.events/erroroccurredeventargs) | 検索ネットワークのノードの一つでエラーが発生したイベントの引数を表します。 |
| [NetworkIndexingProgressEventArgs](../com.groupdocs.search.scaling.events/networkindexingprogresseventargs) | インデックス作成操作の進行状況変更イベントの引数を表します。 |
| [NetworkOptimizationProgressEventArgs](../com.groupdocs.search.scaling.events/networkoptimizationprogresseventargs) | 最適化操作の進行状況変更イベントの引数を表します。 |
| [NodeEventHub](../com.groupdocs.search.scaling.events/nodeeventhub) | サブスクライブ用のノードイベントを提供します。 |
| [StatusChangedEventArgs](../com.groupdocs.search.scaling.events/statuschangedeventargs) | 検索ネットワークのステータス変更イベントの引数を表します。 |

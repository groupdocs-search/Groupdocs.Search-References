## BaseOptions.UseBackupPrivilege property

プロセスがファイルやディレクトリにアクセスする際に SeBackupPrivilege と FILE_FLAG_BACKUP_SEMANTICS を使用すべきかどうかを示す値を取得または設定します。デフォルト値は `false` です。

```csharp
public bool UseBackupPrivilege { get; set; }
```

### Property Value

`true` は SeBackupPrivilege と FILE_FLAG_BACKUP_SEMANTICS を使用した特権アクセスを有効にします。そうでなければ `false` です。

### 備考

有効にすると、プロセスはファイルおよびディレクトリのセキュリティチェックをバイパスでき、通常は ACL によって制限されている保護されたリソースへのアクセスを許可します（プロセスが適切な特権を持っている限り）。この機能は Windows オペレーティングシステムでのみサポートされています。Windows 以外のプラットフォームでは、このプロパティを有効にしても効果はありません。プロセスが管理者権限で実行されている必要があることに注意してください。慎重に使用してください。これは機密システムファイルやユーザーデータへのアクセスを許可する可能性があります。

## SeparateProcessOptions.UseDotnetToStartProcess property

プロセス開始に `dotnet` を使用するフラグを取得または設定します。デフォルト値は `true` です。自己完結型アプリケーションを開始したい場合は、値を `false` に設定してください。古い .NET Framework では `dotnet` が起動に使用されることは決してありません。

```csharp
public bool UseDotnetToStartProcess { get; set; }
```

### Property Value

`dotnet` を使用してプロセスを起動するフラグです。

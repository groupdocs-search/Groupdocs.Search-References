## SeparateProcessOptions.ExtractInSeparateProcess property

ドキュメントからデータを抽出するために別プロセスが使用されるかどうかを示す値を取得または設定します。デフォルト値は `false` です。このオプションが有効な場合、データ抽出は別プロセスで単一スレッドで実行されます。別プロセスで抽出する際は、指定されたスレッド数は無視されます。

```csharp
public bool ExtractInSeparateProcess { get; set; }
```

### Property Value

ドキュメントからデータを抽出するために別プロセスが使用されるかどうかを示す値です。

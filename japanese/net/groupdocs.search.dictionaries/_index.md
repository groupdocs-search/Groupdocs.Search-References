この名前空間は、さまざまな辞書のクラスを提供します。

## クラス

| クラス | 説明 |
| --- | --- |
| [AliasDictionary](./aliasdictionary) | エイリアスの辞書を表します。 |
| [AliasReplacementPair](./aliasreplacementpair) | エイリアス/置換ペアを表します。 |
| [Alphabet](./alphabet) | インデックス作成時に文字種を検出するために使用される文字の辞書を表します。各文字は区切り文字として、文字として、またはその両方として扱うことができます。 |
| [CharacterReplacementDictionary](./characterreplacementdictionary) | インデックス作成プロセスで使用される文字置換辞書を表します。文字置換は、例えばアクセント付き文字からアクセントを除去したり、大小文字を区別しないインデックスを作成したりするために使用できます。 |
| [CharacterReplacementPair](./characterreplacementpair) | 文字と置換のペアを表します。 |
| [DictionaryBase](./dictionarybase) | 辞書の基底クラスを表します。 |
| [DictionaryRepository](./dictionaryrepository) | インデックス内のすべての辞書のリポジトリを表します。 |
| [EnglishWordFormsProvider](./englishwordformsprovider) | 英語の語形提供者を表します。 |
| [HomophoneDictionary](./homophonedictionary) | 異字同音語の辞書を表します。 |
| [PasswordDictionary](./passworddictionary) | 文書パスワードの辞書を表します。 |
| [SpellingCorrector](./spellingcorrector) | クエリ内の語句に対するスペル補正機能を表します。 |
| [StopWordDictionary](./stopworddictionary) | ストップワードの辞書を表します。 |
| [SynonymDictionary](./synonymdictionary) | 同義語の辞書を表します。 |

## Delete(string[], UpdateOptions) {#delete_1}

インデックスからインデックス済みのファイルまたはフォルダーを削除します。その後、削除されたパスなしでインデックスを更新します。フォルダーの一部としてインデックスに追加された場合、個々のドキュメントはインデックスから削除できないことに注意してください。

```csharp
public DeleteResult Delete(string[] paths, UpdateOptions options)
```

| パラメーター | 型 | 説明 |
| --- | --- | --- |
| パス | String[] | 削除するファイルまたはフォルダーへのパス。 |
| オプション | UpdateOptions | 更新オプションです。 |

### 戻り値

インデックスからファイルまたはフォルダーを削除した結果を記述するオブジェクト。

### 例

この例は、インデックスからインデックス化されたパスを削除する方法を示しています。

```csharp
string indexFolder = @"c:\MyIndex\";
string documentsFolder1 = @"c:\MyDocuments\";
string documentsFolder2 = @"c:\MyDocuments2\";

// 指定されたフォルダーにインデックスを作成しています
Index index = new Index(indexFolder);

// 指定されたフォルダーからドキュメントをインデックス化する
index.Add(documentsFolder1);
index.Add(documentsFolder2);

// インデックスからインデックス化されたパスを取得する
string[] indexedPaths1 = index.GetIndexedPaths();

// インデックス化されたパスをコンソールに書き出す
Console.WriteLine("Indexed paths:");
foreach (string path in indexedPaths1)
{
    Console.WriteLine("\t" + path);
}

// インデックスからインデックスパスを削除する
DeleteResult deleteResult = index.Delete(new string[] { documentsFolder1 }, new UpdateOptions());

// 削除後にインデックス化されたパスを取得する
string[] indexedPaths2 = index.GetIndexedPaths();
Console.WriteLine("\nDeleted paths: " + deleteResult.SuccessCount);

Console.WriteLine("\nIndexed paths:");
foreach (string path in indexedPaths2)
{
    Console.WriteLine("\t" + path);
}
```

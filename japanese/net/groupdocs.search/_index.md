この名前空間は、さまざまな形式のドキュメント内のテキストデータをインデックス作成および検索するためのクラスを提供します。この名前空間の主なクラスは次のとおりです：

## クラス

| クラス | 説明 |
| --- | --- |
| [ExtractionHost](./extractionhost) | ドキュメントからデータを抽出するサービス（別プロセス）を表します。 |
| [Extractor](./extractor) | 後続の高速インデックス作成段階を分離するために、ドキュメントからの事前データ抽出ツールを表します。 |
| [Index](./index) | ドキュメントのインデックス作成と検索を行うメインクラスを表します。 |
| [IndexRepository](./indexrepository) | 複数のインデックスを結合し、共通操作を実行するコンテナを表します。 |
| [IndexSettings](./indexsettings) | インデックス作成操作をカスタマイズできるインデックス設定を表します。 |
| [IndexUpdater](./indexupdater) | インデックスアップデータを表します。このクラスは、古いバージョンのインデックス内のドキュメントを再インデックス化します。 |
| [License](./license) | ライセンス適用のためのメソッドを提供します。 |
| [Metered](./metered) | 従量制ライセンスで製品を有効化し、処理された MB の量を取得できるメソッドを提供します。従量制ライセンスの詳細は[こちら](https://purchase.groupdocs.com/faqs/licensing/metered)をご覧ください。 |
| [SearchQuery](./searchquery) | 検索クエリをオブジェクト形式で表します。 |

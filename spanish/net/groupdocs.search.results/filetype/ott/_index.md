## FileType.OTT field

Los archivos con extensión OTT representan documentos plantilla generados por aplicaciones que cumplen con el formato estándar OpenDocument de OASIS. Estos se crean con aplicaciones de procesamiento de texto como el gratuito OpenOffice Writer y pueden contener configuraciones que pueden usarse para generar nuevos documentos a partir de estos archivos plantilla. Obtén más información sobre este formato de archivo [aquí](https://wiki.fileformat.com/word-processing/ott/).

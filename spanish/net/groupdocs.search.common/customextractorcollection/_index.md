## CustomExtractorCollection class

Contiene una colección de extractores personalizados. Si la colección contiene un extractor para alguna extensión de archivo que está cubierta por extractores incorporados, entonces este extractor se usará en lugar del incorporado.

public class CustomExtractorCollection : ICollection<IFieldExtractor>

## EventHub.StatusChanged event

Ocurre cuando el estado del índice cambia.

```csharp
public event EventHandler<BaseIndexEventArgs> StatusChanged;
```

### Ejemplos

El ejemplo muestra cómo usar el evento.

```csharp
string indexFolder = @"c:\MyIndex\";
string documentsFolder = @"c:\MyDocuments\";

// Creando un índice
Index index = new Index(indexFolder);

// Suscribiéndose al evento
index.Events.StatusChanged += (sender, args) =>
{
    if (args.Status != IndexStatus.InProgress)
    {
        // Una notificación de la finalización de la operación debería estar aquí
    }
};

// Estableciendo la bandera para la indexación asíncrona
IndexingOptions options = new IndexingOptions();
options.IsAsync = true;

// Indexación asíncrona de documentos desde la carpeta especificada
// El método termina antes de que la operación se complete
index.Add(documentsFolder, options);
```

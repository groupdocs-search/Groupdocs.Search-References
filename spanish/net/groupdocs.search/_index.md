El espacio de nombres proporciona clases para indexar y buscar datos de texto en documentos de diferentes formatos. Las clases principales en este espacio de nombres son:

## Clases

| Clase | Descripción |
| --- | --- |
| [ExtractionHost](./extractionhost) | Representa un servicio para extraer datos de documentos en un proceso separado. |
| [Extractor](./extractor) | Representa una herramienta para la extracción preliminar de datos de documentos, separando la etapa de indexación rápida posterior. |
| [Index](./index) | Representa la clase principal para indexar documentos y buscar a través de ellos. |
| [IndexRepository](./indexrepository) | Representa un contenedor para combinar múltiples índices y realizar operaciones comunes sobre ellos. |
| [IndexSettings](./indexsettings) | Representa la configuración del índice que permite personalizar las operaciones de indexación. |
| [IndexUpdater](./indexupdater) | Representa un actualizador de índice. Esta clase realiza la reindexación de documentos en un índice de una versión anterior. |
| [License](./license) | Proporciona métodos para aplicar la licencia. |
| [Metered](./metered) | Proporciona métodos que permiten activar el producto con licencia por consumo y obtener la cantidad de MB procesados. Obtenga más información sobre las licencias por consumo [aquí](https://purchase.groupdocs.com/faqs/licensing/metered). |
| [SearchQuery](./searchquery) | Representa una consulta de búsqueda en forma de objeto. |

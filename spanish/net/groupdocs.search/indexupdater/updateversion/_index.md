## IndexUpdater.UpdateVersion method

Realiza la reindexación de documentos en un índice de una versión anterior. El índice actualizado se colocará en el directorio *newIndexPath*. El índice en el directorio *indexPath* no se modificará.

```csharp
public VersionUpdateResult UpdateVersion(string indexPath, string newIndexPath)
```

| Parameter | Type | Descripción |
| --- | --- | --- |
| indexPath | String | La ruta del directorio del índice. |
| newIndexPath | String | El directorio para el índice actualizado. |

### Valor de retorno

El resultado de la operación de actualización de la versión del índice.

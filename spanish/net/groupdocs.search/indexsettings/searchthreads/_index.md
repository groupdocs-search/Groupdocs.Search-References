## IndexSettings.SearchThreads property

Obtiene o establece el número de hilos utilizados para la búsqueda. El valor predeterminado es Default, lo que significa que la búsqueda se realizará usando un número de hilos igual al número de núcleos del procesador.

public NumberOfThreads SearchThreads { get; set; }

### Property Value

El número de hilos utilizados para la búsqueda.

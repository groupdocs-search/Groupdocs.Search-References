## Index.GetIndexedDocuments method

Obtiene una matriz de todos los documentos indexados.

```csharp
public DocumentInfo[] GetIndexedDocuments()
```

### Valor de retorno

Una matriz de todos los documentos indexados.

### Ejemplos

El ejemplo muestra cómo obtener una lista de documentos indexados a partir de un índice.

```csharp
string indexFolder = @"c:\MyIndex\";
string documentsFolder = @"c:\MyDocuments\";
 
// Creando un índice en la carpeta especificada
Index index = new Index(indexFolder);
 
// Indexando documentos de la carpeta especificada
index.Add(documentsFolder);
 
// Obteniendo lista de documentos indexados
DocumentInfo[] documents = index.GetIndexedDocuments();
```

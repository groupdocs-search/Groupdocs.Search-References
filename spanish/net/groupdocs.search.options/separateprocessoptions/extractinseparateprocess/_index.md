## SeparateProcessOptions.ExtractInSeparateProcess property

Obtiene o establece un valor que indica si se utiliza un proceso separado para extraer datos de los documentos. El valor predeterminado es `false`. Cuando esta opción está habilitada, la extracción de datos se realiza en un proceso separado con un solo hilo. El número de hilos especificado se ignora al extraer en un proceso separado.

```csharp
public bool ExtractInSeparateProcess { get; set; }
```

### Property Value

Un valor que indica si se utiliza un proceso separado para extraer datos de los documentos.

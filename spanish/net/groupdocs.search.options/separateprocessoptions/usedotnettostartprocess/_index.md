## SeparateProcessOptions.UseDotnetToStartProcess property

Obtiene o establece la bandera para usar `dotnet` al iniciar el proceso. El valor predeterminado es `true`. Establezca el valor en `false` si desea iniciar una aplicación autónoma. Tenga en cuenta que `dotnet` nunca se usa para iniciar en el antiguo .NET Framework.

```csharp
public bool UseDotnetToStartProcess { get; set; }
```

### Property Value

La bandera para usar `dotnet` al iniciar el proceso.

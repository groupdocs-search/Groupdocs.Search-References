## TextOptions.CustomExtractor property

Obtiene o establece el extractor de texto personalizado que se usó para indexar. El valor predeterminado es `null`. Tenga en cuenta que este valor se usa solo si el texto del documento no se guardó en el índice.

```csharp
public IFieldExtractor CustomExtractor { get; set; }
```

### Property Value

El extractor de texto personalizado que se usó para indexar.

## SpellingCorrectorOptions.ConsiderTranspositions property

Obtiene o establece un valor que indica si el algoritmo debe considerar la transposición de dos caracteres adyacentes como un solo error. El valor predeterminado es `true`.

```csharp
public bool ConsiderTranspositions { get; set; }
```

### Property Value

`true` si el algoritmo del corrector ortográfico considera transposiciones; de lo contrario `false`.

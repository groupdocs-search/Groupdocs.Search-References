## BaseOptions.UseBackupPrivilege property

Obtiene o establece un valor que indica si el proceso debe usar SeBackupPrivilege y FILE_FLAG_BACKUP_SEMANTICS para acceder a archivos y directorios. El valor predeterminado es `false`.

```csharp
public bool UseBackupPrivilege { get; set; }
```

### Property Value

`true` para habilitar el acceso privilegiado usando SeBackupPrivilege y FILE_FLAG_BACKUP_SEMANTICS; de lo contrario, `false`.

### Observaciones

Cuando está habilitado, esto permite que el proceso omita las comprobaciones de seguridad de archivos y directorios, permitiendo el acceso a recursos protegidos típicamente restringidos por ACLs, siempre que el proceso tenga los privilegios adecuados. Esta característica solo es compatible con sistemas operativos Windows. En plataformas que no son Windows, habilitar esta propiedad no tiene efecto. Tenga en cuenta que esto requiere que el proceso se ejecute con derechos administrativos. Úselo con precaución, ya que puede permitir el acceso a archivos del sistema sensibles y datos de usuarios.

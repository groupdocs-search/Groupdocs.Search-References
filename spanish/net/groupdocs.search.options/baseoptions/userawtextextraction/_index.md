## BaseOptions.UseRawTextExtraction property

Obtiene o establece un valor que indica si se usa el modo sin procesar para la extracción de texto cuando sea posible. El valor predeterminado es `false`. El modo sin procesar puede aumentar significativamente la velocidad de indexación, pero el modo normal mejora el formato del texto extraído.

```csharp
public bool UseRawTextExtraction { get; set; }
```

### Property Value

Un valor que indica si se utiliza el modo crudo para la extracción de texto cuando sea posible.

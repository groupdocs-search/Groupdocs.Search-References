## BaseOptions.Encoding property

Obtiene o establece la codificación utilizada para extraer texto de documentos de texto. El valor predeterminado es `null`, lo que significa que se usa la codificación predeterminada UTF-8. Si AutoDetectEncoding es `true`, entonces este valor se usa como la codificación predeterminada.

```csharp
public string Encoding { get; set; }
```

### Property Value

La codificación utilizada para extraer texto de documentos de texto.

### Unknown {#Unknown}

### FB2 {#FB2}
```
public static final FileType FB2
```


Los archivos con extensión FB2 son archivos eBook FictionBook 2.0 que contienen la estructura del eBook.
Se basa en el formato XML y contiene etiquetas especiales para describir cada elemento del libro.
Aprende más sobre este formato de archivo
[here](../https://wiki.fileformat.com/ebook/fb2/).


### TXT {#TXT}
```
public static final FileType TXT
```


Un archivo con extensión .TXT representa un documento de texto que contiene texto plano en forma de líneas.

[here](../https://wiki.fileformat.com/word-processing/txt/).


### LOG {#LOG}
```
public static final FileType LOG
```

```
public static final FileType PPT
```

Un archivo con extensión PPT representa un archivo PowerPoint que consiste en una colección de diapositivas para

[here](../https://wiki.fileformat.com/presentation/ppt/).

pueden contener contenido como texto, imágenes, objetos y estilos.

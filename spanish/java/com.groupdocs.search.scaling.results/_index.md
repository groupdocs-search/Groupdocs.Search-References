El espacio de nombres proporciona las clases de resultados de búsqueda en la red de búsqueda.



## Clases

| Clase | Descripción |
| --- | --- |
| [NetworkDocumentInfo](../com.groupdocs.search.scaling.results/networkdocumentinfo) | Representa un descriptor para un documento indexado en la red de búsqueda. |
| [NetworkFoundDocument](../com.groupdocs.search.scaling.results/networkfounddocument) | Representa un documento encontrado en la red de búsqueda. |
| [NetworkImageSearchResult](../com.groupdocs.search.scaling.results/networkimagesearchresult) | Representa un resultado de búsqueda de imágenes que coincide con una imagen de búsqueda. |
| [NetworkImageSearchToken](../com.groupdocs.search.scaling.results/networkimagesearchtoken) | Representa un token para la continuación de la búsqueda de imágenes por fragmentos de red (búsqueda por páginas). |
| [NetworkSearchResult](../com.groupdocs.search.scaling.results/networksearchresult) | Representa un resultado de búsqueda que coincide con una consulta de búsqueda. |
| [NetworkSearchToken](../com.groupdocs.search.scaling.results/networksearchtoken) | Representa un token para la continuación de la búsqueda por fragmentos de red (búsqueda por páginas). |

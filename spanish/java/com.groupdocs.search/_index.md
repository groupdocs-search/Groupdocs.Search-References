El paquete proporciona clases para indexar y buscar datos de texto en documentos de diferentes formatos. Las clases principales en este paquete son:

Index es el punto de entrada para las operaciones de indexación y búsqueda.

SearchQuery es la clase base y la fábrica para todos los tipos de consultas de búsqueda en forma de objeto.

IndexRepository es una clase contenedora para combinar múltiples índices y realizar operaciones comunes sobre ellos.

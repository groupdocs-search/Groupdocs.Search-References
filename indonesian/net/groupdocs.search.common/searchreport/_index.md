### Contoh

Contoh ini menunjukkan penggunaan tipikal dari kelas tersebut.

```csharp
string indexFolder = @"c:\MyIndex\";
string documentsFolder = @"c:\MyDocuments\";

// Membuat indeks di folder yang ditentukan
Index index = new Index(indexFolder);

// Mengindeks dokumen dari folder yang ditentukan
index.Add(documentsFolder);

// Mencari dalam indeks
SearchResult result1 = index.Search("Einstein");
SearchResult result2 = index.Search("\"Theory of Relativity\"");

// Mendapatkan laporan pencarian
SearchReport[] reports = index.GetSearchReports();

// Mencetak laporan ke konsol
foreach (SearchReport report in reports)
{
    Console.WriteLine("Query: " + report.TextQuery);
    Console.WriteLine("Time: " + report.StartTime);
    Console.WriteLine("Duration: " + report.SearchDuration);
    Console.WriteLine("Documents: " + report.DocumentCount);
    Console.WriteLine("Occurrences: " + report.OccurrenceCount);
    Console.WriteLine();
}
```

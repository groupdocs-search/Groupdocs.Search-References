## BaseOptions.UseBackupPrivilege property

Mendapatkan atau mengatur nilai yang menunjukkan apakah proses harus menggunakan SeBackupPrivilege dan FILE_FLAG_BACKUP_SEMANTICS untuk mengakses file dan direktori. Nilai default adalah `false`.

```csharp
public bool UseBackupPrivilege { get; set; }
```

### Property Value

`true` untuk mengaktifkan akses istimewa menggunakan SeBackupPrivilege dan FILE_FLAG_BACKUP_SEMANTICS; jika tidak, `false`.

### Catatan

Ketika diaktifkan, ini memungkinkan proses melewati pemeriksaan keamanan file dan direktori, memungkinkan akses ke sumber daya terlindungi yang biasanya dibatasi oleh ACL — selama proses memiliki hak istimewa yang tepat. Fitur ini hanya didukung pada sistem operasi Windows. Pada platform non-Windows, mengaktifkan properti ini tidak berpengaruh. Perlu dicatat bahwa ini memerlukan proses berjalan dengan hak administratif. Gunakan dengan hati-hati, karena dapat memungkinkan akses ke file sistem sensitif dan data pengguna.

## FuzzySearchOptions.FuzzyAlgorithm property

Mendapatkan atau mengatur algoritma pencarian fuzzy. Algoritma pencarian fuzzy yang saat ini tersedia adalah [`SimilarityLevel`](../../similaritylevel) dan [`TableDiscreteFunction`](../../tablediscretefunction). Nilai default adalah sebuah instance dari [`SimilarityLevel`](../../similaritylevel) dengan nilai tingkat kemiripan `0.5`.

```csharp
public FuzzyAlgorithm FuzzyAlgorithm { get; set; }
```

### Property Value

Algoritma pencarian fuzzy.

| --- | --- |

### Contoh

Contoh ini menunjukkan cara mengatur algoritma pencarian fuzzy.

```csharp
string indexFolder = @"c:\MyIndex\";
string documentsFolder = @"c:\MyDocuments\";
string query = "Einstein";

Index index = new Index(indexFolder); // Creating an index in the specified folder
index.Add(documentsFolder); // Indexing documents from the specified folder

SearchOptions options = new SearchOptions();
options.FuzzySearch.Enabled = true; // Enabling the fuzzy search
options.FuzzySearch.FuzzyAlgorithm = new TableDiscreteFunction(1, new Step(5, 2), new Step(8, 3)); // Creating the fuzzy search algorithm
// Fungsi ini menentukan 1 sebagai jumlah maksimum kesalahan untuk kata dengan panjang 1 hingga 4 karakter.
// Ini menentukan 2 sebagai jumlah maksimum kesalahan untuk kata dengan panjang 5 hingga 7 karakter.
// Ini menentukan 3 sebagai jumlah maksimum kesalahan untuk kata dengan panjang 8 karakter atau lebih.

SearchResult result = index.Search(query, options); // Search in index
```

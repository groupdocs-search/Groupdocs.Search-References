## Delete(string[], UpdateOptions) {#delete_1}

Menghapus file atau folder yang diindeks dari indeks. Kemudian memperbarui indeks tanpa jalur yang dihapus. Perhatikan bahwa dokumen individu tidak dapat dihapus dari indeks jika ditambahkan ke indeks sebagai bagian dari sebuah folder.

```csharp
public DeleteResult Delete(string[] paths, UpdateOptions options)
```

| Parameter | Type | Deskripsi |
| --- | --- | --- |
| jalur | String[] | Jalur ke file atau folder yang akan dihapus. |
| opsi | UpdateOptions | Opsi pembaruan. |

### Nilai Kembali

Objek yang menjelaskan hasil penghapusan file atau folder dari indeks.

### Contoh

Contoh ini menunjukkan cara menghapus jalur yang diindeks dari sebuah indeks.

```csharp
string indexFolder = @"c:\MyIndex\";
string documentsFolder1 = @"c:\MyDocuments\";
string documentsFolder2 = @"c:\MyDocuments2\";

// Membuat indeks di folder yang ditentukan
Index index = new Index(indexFolder);

// Mengindeks dokumen dari folder yang ditentukan
index.Add(documentsFolder1);
index.Add(documentsFolder2);

// Mendapatkan jalur yang diindeks dari indeks
string[] indexedPaths1 = index.GetIndexedPaths();

// Menulis jalur yang diindeks ke konsol
Console.WriteLine("Indexed paths:");
foreach (string path in indexedPaths1)
{
    Console.WriteLine("\t" + path);
}

// Menghapus jalur indeks dari indeks
DeleteResult deleteResult = index.Delete(new string[] { documentsFolder1 }, new UpdateOptions());

// Mendapatkan jalur yang diindeks setelah penghapusan
string[] indexedPaths2 = index.GetIndexedPaths();
Console.WriteLine("\nDeleted paths: " + deleteResult.SuccessCount);

Console.WriteLine("\nIndexed paths:");
foreach (string path in indexedPaths2)
{
    Console.WriteLine("\t" + path);
}
```

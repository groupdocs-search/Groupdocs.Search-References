### Contoh

Contoh ini menunjukkan cara menyorot kemunculan dalam teks berformat HTML.

```csharp
string indexFolder = @"c:\MyIndex\";
string documentFolder = @"c:\MyDocuments\";

// Membuat indeks
Index index = new Index(indexFolder);

// Mengindeks dokumen dari folder yang ditentukan
index.Add(documentFolder);

// Cari kata 'eternity'
SearchResult result = index.Search("eternity");

    options.TermsBefore = 5;
    options.TermsAfter = 5;
    options.TermsTotal = 15;
    index.Highlight(document, highlighter, options); // Generating HTML formatted text with highlighted occurrences
```

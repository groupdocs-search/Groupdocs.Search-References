Namespace ini menyediakan kelas untuk mengindeks dan mencari data teks dalam dokumen dengan berbagai format. Kelas utama dalam namespace ini adalah:

## Kelas

| Kelas | Deskripsi |
| --- | --- |
| [ExtractionHost](./extractionhost) | Mewakili layanan untuk mengekstrak data dari dokumen dalam proses terpisah. |
| [Extractor](./extractor) | Mewakili alat untuk ekstraksi data awal dari dokumen guna memisahkan tahap pengindeksan cepat berikutnya. |
| [Index](./index) | Mewakili kelas utama untuk mengindeks dokumen dan mencari di dalamnya. |
| [IndexRepository](./indexrepository) | Mewakili wadah untuk menggabungkan beberapa indeks dan melakukan operasi umum pada mereka. |
| [IndexSettings](./indexsettings) | Mewakili pengaturan indeks yang memungkinkan penyesuaian operasi pengindeksan. |
| [IndexUpdater](./indexupdater) | Mewakili pembaruan indeks. Kelas ini melakukan pengindeksan ulang dokumen dalam indeks versi lama. |
| [License](./license) | Menyediakan metode untuk menerapkan lisensi. |
| [Metered](./metered) | Menyediakan metode yang memungkinkan mengaktifkan produk dengan lisensi Metered dan mengambil jumlah MB yang diproses. Pelajari lebih lanjut tentang lisensi Metered [di sini](https://purchase.groupdocs.com/faqs/licensing/metered). |
| [SearchQuery](./searchquery) | Mewakili kueri pencarian dalam bentuk objek. |

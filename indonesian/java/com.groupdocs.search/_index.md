Paket ini menyediakan kelas untuk mengindeks dan mencari data teks dalam dokumen dengan berbagai format. Kelas utama dalam paket ini adalah:

Index adalah titik masuk untuk operasi pengindeksan dan pencarian.

SearchQuery adalah kelas dasar dan pabrik untuk semua jenis kueri pencarian dalam bentuk objek.

IndexRepository adalah kelas kontainer untuk menggabungkan beberapa indeks dan melakukan operasi umum pada mereka.



## Kelas

| Kelas | Deskripsi |
| --- | --- |
| [Action](../com.groupdocs.search/action) | Mengkapsulkan metode yang tidak memiliki parameter dan tidak mengembalikan nilai. |
| [Action1<T>](../com.groupdocs.search/action1) | Mengkapsulkan metode yang memiliki satu parameter dan tidak mengembalikan nilai. |
| [Action2<T1,T2>](../com.groupdocs.search/action2) | Mengkapsulkan metode yang memiliki dua parameter dan tidak mengembalikan nilai. |

| [DocumentFilter](../com.groupdocs.search/documentfilter) | Mewakili kelas dasar untuk filter dokumen. |
| [ExtractedData](../com.groupdocs.search/extracteddata) | Mewakili data yang diambil dari dokumen dan disiapkan untuk pengindeksan. |
| [Extractor](../com.groupdocs.search/extractor) | Mewakili alat untuk ekstraksi data awal dari dokumen guna memisahkan tahap pengindeksan cepat berikutnya. |

## FileType.ASF field

Het Advanced Systems Format (ASF) is een digitale multimedia-container die voornamelijk is ontworpen voor het opslaan en verzenden van mediastreams. Microsoft Windows Media Video (WMV) is het gecomprimeerde videoformaat en Microsoft Windows Media Audio (WMA) is het gecomprimeerde audioformaat, samen met extra metadata in de door Microsoft ontwikkelde ASF-container. Meer informatie over dit bestandsformaat vind je [hier](https://wiki.fileformat.com/video/wmv/).

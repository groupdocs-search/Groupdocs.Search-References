## SeparateProcessOptions.UseDotnetToStartProcess property

Haalt op of stelt de vlag voor het gebruik van `dotnet` om het proces te starten in. De standaardwaarde is `true`. Stel de waarde in op `false` als u een zelfstandige applicatie wilt starten. Merk op dat `dotnet` nooit wordt gebruikt om te starten op het oude .NET Framework.

```csharp
public bool UseDotnetToStartProcess { get; set; }
```

### Property Value

De vlag voor het gebruik van `dotnet` om het proces te starten.

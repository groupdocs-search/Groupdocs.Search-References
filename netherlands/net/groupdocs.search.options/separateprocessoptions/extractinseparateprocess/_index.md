## SeparateProcessOptions.ExtractInSeparateProcess property

Haalt op of stelt een waarde in die aangeeft of een afzonderlijk proces wordt gebruikt om gegevens uit documenten te extraheren. De standaardwaarde is `false`. Wanneer deze optie is ingeschakeld, wordt gegevensextractie uitgevoerd in een afzonderlijk proces met slechts één thread. Het opgegeven aantal threads wordt genegeerd bij extractie in een afzonderlijk proces.

```csharp
public bool ExtractInSeparateProcess { get; set; }
```

### Property Value

Een waarde die aangeeft of een afzonderlijk proces wordt gebruikt om gegevens uit documenten te extraheren.

## BaseOptions.UseRawTextExtraction property

Haalt op of stelt een waarde in die aangeeft of de ruwe modus wordt gebruikt voor tekstextractie indien mogelijk. De standaardwaarde is `false`. De ruwe modus kan de indexeringssnelheid aanzienlijk verhogen, maar de normale modus verbetert de opmaak van de geëxtraheerde tekst.

```csharp
public bool UseRawTextExtraction { get; set; }
```

### Property Value

Een waarde die aangeeft of de ruwe modus wordt gebruikt voor tekstelextractie indien mogelijk.

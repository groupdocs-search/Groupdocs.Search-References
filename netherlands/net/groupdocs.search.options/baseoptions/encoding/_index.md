## BaseOptions.Encoding property

Haalt op of stelt de codering in die wordt gebruikt om tekst uit tekstdocumenten te extraheren. De standaardwaarde is `null`, wat betekent dat de standaardcodering UTF-8 wordt gebruikt. Als AutoDetectEncoding `true` is, wordt deze waarde als de standaardcodering gebruikt.

```csharp
public string Encoding { get; set; }
```

### Property Value

De codering die wordt gebruikt om tekst uit tekstdocumenten te extraheren.

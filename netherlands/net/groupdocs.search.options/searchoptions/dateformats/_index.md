## SearchOptions.DateFormats property

Haalt de verzameling datumformaten op voor datumreeks zoeken. De standaard datumformaten zijn 'dd.MM.yyyy', 'MM/dd/yyyy' en 'yyyy-MM-dd'.

```csharp
public DateFormatCollection DateFormats { get; }
```

### Property Value

De collectie datumformaten voor datumreeks zoeken.

### Voorbeelden

Het voorbeeld toont hoe de datumformaten voor de zoekopdracht in te stellen.

```csharp
string indexFolder = @"c:\MyIndex\";
string documentsFolder = @"c:\MyDocuments\";
string query = "Einstein";

Index index = new Index(indexFolder); // Creating an index in the specified folder
index.Add(documentsFolder); // Indexing documents from the specified folder

SearchOptions options = new SearchOptions();
options.DateFormats.Clear(); // Removing default date formats
DateFormatElement[] elements = new DateFormatElement[]
{
    DateFormatElement.MonthTwoDigits,
    DateFormatElement.DayOfMonthTwoDigits,
    DateFormatElement.YearFourDigits,
};
// Een datumformaatpatroon 'MM/dd/yyyy' aanmaken.
DateFormat dateFormat = new DateFormat(elements, "/");
options.DateFormats.Add(dateFormat);

SearchResult result = index.Search(query, options); // Search in index
```

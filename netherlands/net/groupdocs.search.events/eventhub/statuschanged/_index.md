## EventHub.StatusChanged event

Treedt op wanneer de indexstatus verandert.

```csharp
public event EventHandler<BaseIndexEventArgs> StatusChanged;
```

### Voorbeelden

Het voorbeeld toont hoe het evenement te gebruiken.

```csharp
string indexFolder = @"c:\MyIndex\";
string documentsFolder = @"c:\MyDocuments\";

// Een index maken
Index index = new Index(indexFolder);

// Abonneren op het evenement
index.Events.StatusChanged += (sender, args) =>
{
    if (args.Status != IndexStatus.InProgress)
    {
        // Een melding van de voltooiing van de bewerking zou hier moeten staan
    }
};

// Instellen van de vlag voor asynchrone indexering
IndexingOptions options = new IndexingOptions();
options.IsAsync = true;

// Asynchrone indexering van documenten uit de opgegeven map
// De methode beëindigt voordat de bewerking voltooid is.
index.Add(documentsFolder, options);
```

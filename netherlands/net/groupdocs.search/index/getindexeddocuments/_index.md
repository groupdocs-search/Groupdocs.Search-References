## Index.GetIndexedDocuments method

Haalt een array op van alle geïndexeerde documenten.

```csharp
public DocumentInfo[] GetIndexedDocuments()
```

### Retourwaarde

Een array van alle geïndexeerde documenten.

### Voorbeelden

Het voorbeeld toont hoe een lijst met geïndexeerde documenten uit een index kan worden verkregen.

```csharp
string indexFolder = @"c:\MyIndex\";
string documentsFolder = @"c:\MyDocuments\";
 
// Een index aanmaken in de opgegeven map
Index index = new Index(indexFolder);
 
// Documenten indexeren vanuit de opgegeven map
index.Add(documentsFolder);
 
// Lijst met geïndexeerde documenten ophalen
DocumentInfo[] documents = index.GetIndexedDocuments();
```

Ο χώρος ονομάτων παρέχει τις κλάσεις αποτελεσμάτων αναζήτησης στο δίκτυο αναζήτησης.



## Κλάσεις

| Κλάση | Περιγραφή |
| --- | --- |
| [NetworkDocumentInfo](../com.groupdocs.search.scaling.results/networkdocumentinfo) | Αντιπροσωπεύει έναν περιγραφέα για ένα ευρετηριασμένο έγγραφο στο δίκτυο αναζήτησης. |
| [NetworkFoundDocument](../com.groupdocs.search.scaling.results/networkfounddocument) | Αντιπροσωπεύει ένα βρεθέν έγγραφο στο δίκτυο αναζήτησης. |
| [NetworkImageSearchResult](../com.groupdocs.search.scaling.results/networkimagesearchresult) | Αντιπροσωπεύει ένα αποτέλεσμα αναζήτησης εικόνας που ταιριάζει με μια εικόνα αναζήτησης. |
| [NetworkImageSearchToken](../com.groupdocs.search.scaling.results/networkimagesearchtoken) | Αντιπροσωπεύει ένα διακριτικό για τη συνέχιση της αναζήτησης εικόνας κατά τμήματα στο δίκτυο (αναζήτηση ανά σελίδες). |
| [NetworkSearchResult](../com.groupdocs.search.scaling.results/networksearchresult) | Αντιπροσωπεύει ένα αποτέλεσμα αναζήτησης που ταιριάζει με ένα ερώτημα αναζήτησης. |
| [NetworkSearchToken](../com.groupdocs.search.scaling.results/networksearchtoken) | Αντιπροσωπεύει ένα διακριτικό για τη συνέχιση της αναζήτησης κατά τμήματα στο δίκτυο (αναζήτηση ανά σελίδες). |

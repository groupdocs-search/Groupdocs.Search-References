Το πακέτο παρέχει κλάσεις για την ευρετηρίαση και την αναζήτηση δεδομένων κειμένου σε έγγραφα διαφορετικών μορφών. Οι κύριες κλάσεις σε αυτό το πακέτο είναι:

Η Index είναι το σημείο εισόδου για τις λειτουργίες ευρετηρίασης και αναζήτησης.

Η SearchQuery είναι η βασική κλάση και το εργοστάσιο για όλους τους τύπους ερωτημάτων αναζήτησης σε μορφή αντικειμένου.

Η IndexRepository είναι μια κλάση-δοχείο για τη συνδυασμό πολλαπλών ευρετηρίων και την εκτέλεση κοινών λειτουργιών πάνω σε αυτά.

### FB2 {#FB2}
```
public static final FileType FB2
```


Τα αρχεία με επέκταση FB2 είναι αρχεία eBook FictionBook 2.0 που περιέχουν τη δομή του eBook.
Βασίζεται στη μορφή XML και περιέχει ειδικές ετικέτες για την περιγραφή κάθε στοιχείου του βιβλίου.
Μάθετε περισσότερα για αυτή τη μορφή αρχείου
[here](../https://wiki.fileformat.com/ebook/fb2/).

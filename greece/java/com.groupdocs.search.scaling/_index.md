Ο χώρος ονομάτων παρέχει κλάσεις λειτουργικότητας κλιμάκωσης.



## Κλάσεις

| Κλάση | Περιγραφή |
| --- | --- |
| [Indexer](../com.groupdocs.search.scaling/indexer) | Αντιπροσωπεύει μια υπηρεσία που διαχειρίζεται τη διανομή των ευρετηριασμένων εγγράφων σε τμήματα του δικτύου αναζήτησης. |
| [SearchNetworkNode](../com.groupdocs.search.scaling/searchnetworknode) | Αντιπροσωπεύει έναν κόμβο δικτύου αναζήτησης που μπορεί να περιέχει υπηρεσίες όπως εξαγωγέας, ευρετηριαστής, αναζητητής, τμήμα. |
| [Searcher](../com.groupdocs.search.scaling/searcher) | Αντιπροσωπεύει μια υπηρεσία που διαχειρίζεται ερωτήματα αναζήτησης προς τα τμήματα του δικτύου αναζήτησης. |

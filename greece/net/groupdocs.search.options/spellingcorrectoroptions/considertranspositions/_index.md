## SpellingCorrectorOptions.ConsiderTranspositions property

```csharp
public bool ConsiderTranspositions { get; set; }
```

### Property Value

`true` εάν ο αλγόριθμος διορθωτή ορθογραφίας θεωρεί τις αντιστροφές· διαφορετικά `false`.

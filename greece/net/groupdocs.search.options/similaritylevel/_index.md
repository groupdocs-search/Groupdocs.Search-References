## SimilarityLevel class

Αντιπροσωπεύει έναν αλγόριθμο ασαφούς αναζήτησης που καθορίζει το επίπεδο ομοιότητας. Ο αλγόριθμος επιπέδου ομοιότητας υπολογίζει το μέγιστο αριθμό λαθών για μια λέξη ως αντιστρόφως ανάλογο του μήκους της λέξης.

### Παραδείγματα

Το παράδειγμα δείχνει μια τυπική χρήση της κλάσης.

```csharp
string indexFolder = @"c:\MyIndex\";
string documentsFolder = @"c:\MyDocuments\";
string query = "Einstein";

Index index = new Index(indexFolder); // Creating an index in the specified folder
index.Add(documentsFolder); // Indexing documents from the specified folder

SearchOptions options = new SearchOptions();
options.FuzzySearch.Enabled = true; // Enabling the fuzzy search
options.FuzzySearch.FuzzyAlgorithm = new SimilarityLevel(0.8); // Creating the fuzzy search algorithm
// Αυτή η λειτουργία ορίζει το 0 ως μέγιστο αριθμό σφαλμάτων για λέξεις από 1 έως 4 χαρακτήρες.
// Ορίζει το 1 ως μέγιστο αριθμό σφαλμάτων για λέξεις από 5 έως 9 χαρακτήρες.
// Ορίζει το 2 ως μέγιστο αριθμό σφαλμάτων για λέξεις από 10 έως 14 χαρακτήρες. Και ούτω καθεξής.

SearchResult result = index.Search(query, options); // Search in index
```

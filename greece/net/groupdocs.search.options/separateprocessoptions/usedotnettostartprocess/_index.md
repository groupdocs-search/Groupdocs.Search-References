## SeparateProcessOptions.UseDotnetToStartProcess property

Λαμβάνει ή ορίζει τη σημαία για τη χρήση του `dotnet` για την εκκίνηση της διαδικασίας. Η προεπιλεγμένη τιμή είναι `true`. Ορίστε την τιμή σε `false` εάν θέλετε να ξεκινήσετε μια αυτόνομη εφαρμογή. Σημειώστε ότι το `dotnet` δεν χρησιμοποιείται ποτέ για την εκκίνηση στο παλιό .NET Framework.

public bool UseDotnetToStartProcess { get; set; }

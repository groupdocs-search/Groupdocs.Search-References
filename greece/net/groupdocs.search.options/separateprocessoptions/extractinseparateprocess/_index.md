## SeparateProcessOptions.ExtractInSeparateProcess property

Λαμβάνει ή ορίζει μια τιμή που υποδεικνύει εάν χρησιμοποιείται ξεχωριστή διαδικασία για την εξαγωγή δεδομένων από έγγραφα. Η προεπιλεγμένη τιμή είναι `false`. Όταν αυτή η επιλογή είναι ενεργοποιημένη, η εξαγωγή δεδομένων εκτελείται σε ξεχωριστή διαδικασία σε μόνο ένα νήμα. Ο καθορισμένος αριθμός νημάτων αγνοείται κατά την εξαγωγή σε ξεχωριστή διαδικασία.

```csharp
public bool ExtractInSeparateProcess { get; set; }
```

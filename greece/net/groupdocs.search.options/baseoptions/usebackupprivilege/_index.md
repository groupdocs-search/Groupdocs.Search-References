## BaseOptions.UseBackupPrivilege property

Λαμβάνει ή ορίζει μια τιμή που υποδεικνύει εάν η διαδικασία πρέπει να χρησιμοποιεί το SeBackupPrivilege και το FILE_FLAG_BACKUP_SEMANTICS για πρόσβαση σε αρχεία και καταλόγους. Η προεπιλεγμένη τιμή είναι `false`.

```csharp
public bool UseBackupPrivilege { get; set; }
```

### Property Value

`true` για ενεργοποίηση προνομιακής πρόσβασης χρησιμοποιώντας το SeBackupPrivilege και το FILE_FLAG_BACKUP_SEMANTICS· διαφορετικά, `false`.

### Σχόλια

Όταν είναι ενεργοποιημένο, αυτό επιτρέπει στη διαδικασία να παρακάμπτει τους ελέγχους ασφαλείας αρχείων και καταλόγων, επιτρέποντας πρόσβαση σε προστατευμένους πόρους που συνήθως περιορίζονται από ACLs — εφόσον η διαδικασία διαθέτει τα κατάλληλα προνόμια. Αυτή η δυνατότητα υποστηρίζεται μόνο σε λειτουργικά συστήματα Windows. Σε πλατφόρμες που δεν είναι Windows, η ενεργοποίηση αυτής της ιδιότητας δεν έχει καμία επίδραση. Σημειώστε ότι απαιτεί τη λειτουργία της διαδικασίας με διαχειριστικά δικαιώματα. Χρησιμοποιήστε με προσοχή, καθώς μπορεί να επιτρέψει πρόσβαση σε ευαίσθητα αρχεία συστήματος και δεδομένα χρηστών.

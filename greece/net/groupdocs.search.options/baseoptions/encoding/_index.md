## BaseOptions.Encoding property

Λαμβάνει ή ορίζει την κωδικοποίηση που χρησιμοποιείται για την εξαγωγή κειμένου από έγγραφα κειμένου. Η προεπιλεγμένη τιμή είναι `null`, που σημαίνει ότι χρησιμοποιείται η προεπιλεγμένη κωδικοποίηση UTF-8. Εάν το AutoDetectEncoding είναι `true`, τότε αυτή η τιμή χρησιμοποιείται ως προεπιλεγμένη κωδικοποίηση.

```csharp
public string Encoding { get; set; }
```

### Property Value

Η κωδικοποίηση που χρησιμοποιείται για την εξαγωγή κειμένου από έγγραφα κειμένου.

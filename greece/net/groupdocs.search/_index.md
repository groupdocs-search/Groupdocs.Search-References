Ο ονοματοχώρος παρέχει κλάσεις για την ευρετηρίαση και αναζήτηση δεδομένων κειμένου σε έγγραφα διαφορετικών μορφών. Οι κύριες κλάσεις σε αυτόν τον ονοματοχώρο είναι:

## Κλάσεις

| Κλάση | Περιγραφή |
| --- | --- |
| [ExtractionHost](./extractionhost) | Αντιπροσωπεί μια υπηρεσία για την εξαγωγή δεδομένων από έγγραφα σε ξεχωριστή διεργασία. |
| [Extractor](./extractor) | Αντιπροσωπεί ένα εργαλείο για προκαταρκτική εξαγωγή δεδομένων από έγγραφα, προκειμένου να διαχωριστεί το στάδιο της επακόλουθης γρήγορης ευρετηρίασης. |
| [Index](./index) | Αντιπροσωπεί την κύρια κλάση για την ευρετηρίαση εγγράφων και την αναζήτηση σε αυτά. |
| [IndexRepository](./indexrepository) | Αντιπροσωπεί ένα δοχείο για τη συνένωση πολλαπλών ευρετηρίων και την εκτέλεση κοινών λειτουργιών σε αυτά. |
| [IndexSettings](./indexsettings) | Αντιπροσωπεί τις ρυθμίσεις ευρετηρίου που επιτρέπουν την προσαρμογή των λειτουργιών ευρετηρίασης. |
| [IndexUpdater](./indexupdater) | Αντιπροσωπεί έναν ενημερωτή ευρετηρίου. Αυτή η κλάση εκτελεί επανευρετηρίαση εγγράφων σε ευρετήριο παλαιότερης έκδοσης. |
| [License](./license) | Παρέχει μεθόδους για την εφαρμογή άδειας. |
| [Metered](./metered) | Παρέχει μεθόδους που επιτρέπουν την ενεργοποίηση του προϊόντος με άδεια Metered και την ανάκτηση του ποσού των επεξεργασμένων MB. Μάθετε περισσότερα για τις άδειες Metered [here](https://purchase.groupdocs.com/faqs/licensing/metered). |
| [SearchQuery](./searchquery) | Αντιπροσωπεί ένα ερώτημα αναζήτησης σε μορφή αντικειμένου. |

## Delete(string[], UpdateOptions) {#delete_1}

Διαγράφει τα ευρετηριασμένα αρχεία ή φακέλους από το ευρετήριο. Στη συνέχεια ενημερώνει το ευρετήριο χωρίς τις διαγραμμένες διαδρομές. Σημειώστε ότι ένα μεμονωμένο έγγραφο δεν μπορεί να διαγραφεί από το ευρετήριο εάν προστέθηκε στο ευρετήριο ως μέρος φακέλου.

```csharp
public DeleteResult Delete(string[] paths, UpdateOptions options)
```

| Parameter | Type | Περιγραφή |
| --- | --- | --- |
| paths | String[] | Οι διαδρομές προς αρχεία ή φακέλους για διαγραφή. |
| επιλογές | UpdateOptions | Οι επιλογές ενημέρωσης. |

### Τιμή Επιστροφής

Ένα αντικείμενο που περιγράφει το αποτέλεσμα της διαγραφής αρχείων ή φακέλων από το ευρετήριο.

### Παραδείγματα

Το παράδειγμα δείχνει πώς να διαγράψετε ευρετηριασμένες διαδρομές από ένα ευρετήριο.

```csharp
string indexFolder = @"c:\MyIndex\";
string documentsFolder1 = @"c:\MyDocuments\";
string documentsFolder2 = @"c:\MyDocuments2\";

// Δημιουργία ευρετηρίου στον καθορισμένο φάκελο
Index index = new Index(indexFolder);

// Ευρετηρίαση εγγράφων από τους καθορισμένους φακέλους
index.Add(documentsFolder1);
index.Add(documentsFolder2);

// Λήψη ευρετηριασμένων διαδρομών από το ευρετήριο
string[] indexedPaths1 = index.GetIndexedPaths();

// Εγγραφή ευρετηριασμένων διαδρομών στην κονσόλα
Console.WriteLine("Indexed paths:");
foreach (string path in indexedPaths1)
{
    Console.WriteLine("\t" + path);
}

// Διαγραφή διαδρομής ευρετηρίου από το ευρετήριο
DeleteResult deleteResult = index.Delete(new string[] { documentsFolder1 }, new UpdateOptions());

// Λήψη ευρετηριασμένων διαδρομών μετά τη διαγραφή
string[] indexedPaths2 = index.GetIndexedPaths();
Console.WriteLine("\nDeleted paths: " + deleteResult.SuccessCount);

Console.WriteLine("\nIndexed paths:");
foreach (string path in indexedPaths2)
{
    Console.WriteLine("\t" + path);
}
```

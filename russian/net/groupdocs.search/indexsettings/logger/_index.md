## IndexSettings.Logger property

Получает или задает регистратор, используемый для записи событий и ошибок в индексе. Обратите внимание, что регистратор не сохраняется и должен создаваться и назначаться каждый раз при создании или загрузке индекса.

```csharp
public ILogger Logger { get; set; }
```

### Property Value

Логгер, который используется для записи событий и ошибок в индексе.

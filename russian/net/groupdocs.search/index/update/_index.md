Переиндексирует документы, которые были изменены или удалены с момента последнего обновления. Добавляет новые файлы, которые были добавлены в проиндексированные папки.


### Примеры

В примере показано, как обновить индекс с определёнными параметрами обновления.

```csharp
string indexFolder = @"c:\MyIndex\";
string documentsFolder = @"c:\MyDocuments\";

Index index = new Index(indexFolder); // Creating index in the specified folder
index.Add(documentsFolder); // Indexing documents from the specified folder

// Удалить документы из папки документов или изменить их, либо добавить новые документы в папку

options.Threads = 2; // Setting the number of indexing threads
index.Update(options); // Updating the index
```

## Optimize() {#optimize}

Уменьшает количество сегментов индекса, объединяя их друг с другом. Эта операция улучшает производительность поиска.

```csharp
public void Optimize()
```

В примере демонстрируется, как объединять сегменты индекса.

```csharp

string documentsFolder1 = @"c:\MyDocuments1\";
string documentsFolder2 = @"c:\MyDocuments2\";
string documentsFolder3 = @"c:\MyDocuments3\";

Index index = new Index(indexFolder); // Creating index in the specified folder

index.Add(documentsFolder1); // Indexing documents from the specified folder
index.Add(documentsFolder2); // Each call to Add creates at least one new segment in the index
index.Add(documentsFolder3);

// Объединение сегментов индекса
index.Optimize();
```

В примере демонстрируется, как объединять сегменты индекса с определёнными параметрами слияния.

```csharp
options.IsAsync = true; // Asynchronous operation

// Объединение сегментов индекса

options.Cancellation.CancelAfter(10000); // Setting maximum duration of the operation to 10 seconds
```

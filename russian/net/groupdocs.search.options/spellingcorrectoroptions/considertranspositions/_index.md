## SpellingCorrectorOptions.ConsiderTranspositions property

Получает или задаёт значение, указывающее, должен ли алгоритм рассматривать транспозицию двух соседних символов как одну ошибку. Значение по умолчанию — `true`.

```csharp
public bool ConsiderTranspositions { get; set; }
```

### Property Value

`true`, если алгоритм корректора орфографии учитывает перестановки; иначе `false`.

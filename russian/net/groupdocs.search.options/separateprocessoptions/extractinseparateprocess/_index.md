## SeparateProcessOptions.ExtractInSeparateProcess property

Возвращает или задает значение, указывающее, используется ли отдельный процесс для извлечения данных из документов. Значение по умолчанию — `false`. Когда эта опция включена, извлечение данных выполняется в отдельном процессе только в одном потоке. Указанное количество потоков игнорируется при извлечении в отдельном процессе.

```csharp
public bool ExtractInSeparateProcess { get; set; }
```

### Property Value

Значение, указывающее, используется ли отдельный процесс для извлечения данных из документов.

## SeparateProcessOptions.UseDotnetToStartProcess property

Возвращает или задает флаг использования `dotnet` для запуска процесса. Значение по умолчанию — `true`. Установите значение `false`, если хотите запустить автономное приложение. Обратите внимание, что `dotnet` никогда не используется для запуска на старой платформе .NET Framework.

```csharp
public bool UseDotnetToStartProcess { get; set; }
```

### Property Value

Флаг использования `dotnet` для запуска процесса.

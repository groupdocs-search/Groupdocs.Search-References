## BaseOptions.UseBackupPrivilege property

Получает или задает значение, указывающее, следует ли процессу использовать SeBackupPrivilege и FILE_FLAG_BACKUP_SEMANTICS для доступа к файлам и каталогам. Значение по умолчанию — `false`.

```csharp
public bool UseBackupPrivilege { get; set; }
```

### Property Value

`true` для включения привилегированного доступа с использованием SeBackupPrivilege и FILE_FLAG_BACKUP_SEMANTICS; иначе `false`.

### Примечания

При включении это позволяет процессу обходить проверки безопасности файлов и каталогов, предоставляя доступ к защищённым ресурсам, обычно ограниченным списками контроля доступа (ACL) — при условии, что у процесса есть соответствующие привилегии. Эта функция поддерживается только в операционных системах Windows. На платформах, отличных от Windows, включение этого свойства не оказывает влияния. Обратите внимание, что для этого процесс должен работать с правами администратора. Используйте с осторожностью, так как это может предоставить доступ к конфиденциальным системным файлам и пользовательским данным.

## BaseOptions.UseRawTextExtraction property

Получает или задает значение, указывающее, используется ли необработанный режим для извлечения текста, если это возможно. Значение по умолчанию — `false`. Необработанный режим может значительно увеличить скорость индексирования, но обычный режим улучшает форматирование извлечённого текста.

```csharp
public bool UseRawTextExtraction { get; set; }
```

### Property Value

Значение, указывающее, используется ли raw mode для извлечения текста, если это возможно.

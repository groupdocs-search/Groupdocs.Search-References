## BaseOptions.Encoding property

Получает или задает кодировку, используемую для извлечения текста из текстовых документов. Значение по умолчанию — `null`, что означает использование кодировки UTF-8 по умолчанию. Если AutoDetectEncoding равно `true`, то это значение используется как кодировка по умолчанию.

public string Encoding { get; set; }

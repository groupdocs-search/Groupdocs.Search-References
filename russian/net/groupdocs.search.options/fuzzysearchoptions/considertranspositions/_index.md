## FuzzySearchOptions.ConsiderTranspositions property

Получает или задает значение, указывающее, должен ли алгоритм нечеткого поиска учитывать транспозицию двух соседних символов как одну ошибку. Значение по умолчанию — `true`.

```csharp
public bool ConsiderTranspositions { get; set; }
```

### Property Value

`true`, если алгоритм нечеткого поиска учитывает транспозиции; иначе `false`.

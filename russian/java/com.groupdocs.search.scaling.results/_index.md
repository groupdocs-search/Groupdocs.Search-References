Пространство имён предоставляет классы результатов поиска в поисковой сети.



## Классы

| Класс | Описание |
| --- | --- |
| [NetworkDocumentInfo](../com.groupdocs.search.scaling.results/networkdocumentinfo) | Представляет дескриптор проиндексированного документа в поисковой сети. |
| [NetworkFoundDocument](../com.groupdocs.search.scaling.results/networkfounddocument) | Представляет найденный документ в поисковой сети. |
| [NetworkImageSearchResult](../com.groupdocs.search.scaling.results/networkimagesearchresult) | Представляет результат поиска изображений, соответствующий поисковому изображению. |
| [NetworkImageSearchToken](../com.groupdocs.search.scaling.results/networkimagesearchtoken) | Представляет токен для продолжения поиска по частям сети изображений (поиск по страницам). |
| [NetworkSearchResult](../com.groupdocs.search.scaling.results/networksearchresult) | Представляет результат поиска, соответствующий поисковому запросу. |
| [NetworkSearchToken](../com.groupdocs.search.scaling.results/networksearchtoken) | Представляет токен для продолжения поиска по частям сети (поиск по страницам). |

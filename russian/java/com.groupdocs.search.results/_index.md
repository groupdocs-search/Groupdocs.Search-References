Пакет предоставляет классы результатов поиска.



## Классы

| Класс | Описание |
| --- | --- |
| [DeleteResult](../com.groupdocs.search.results/deleteresult) | Представляет результат операции удаления проиндексированных файлов или папок из индекса. |
| [DocumentInfo](../com.groupdocs.search.results/documentinfo) | Представляет дескриптор проиндексированного документа. |
| [FileType](../com.groupdocs.search.results/filetype) | Представляет тип файла. |
| [FormatFamily](../com.groupdocs.search.results/formatfamily) | Указывает семейство форматов, объединяющее несколько похожих форматов. |
| [FoundDocument](../com.groupdocs.search.results/founddocument) | Представляет найденный документ. |
| [FoundDocumentField](../com.groupdocs.search.results/founddocumentfield) | Представляет найденное поле документа. |
| [FoundImageFrame](../com.groupdocs.search.results/foundimageframe) | Представляет найденный кадр изображения. |
| [ImageSearchResult](../com.groupdocs.search.results/imagesearchresult) | Представляет результат обратного поиска изображения. |
| [PathDeleteResult](../com.groupdocs.search.results/pathdeleteresult) | Представляет результат операции удаления проиндексированного файла или папки из индекса. |
| [SearchResult](../com.groupdocs.search.results/searchresult) | Представляет результат поиска, соответствующий поисковому запросу. |

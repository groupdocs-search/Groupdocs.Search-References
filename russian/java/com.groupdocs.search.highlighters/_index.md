Пакет предоставляет подсветки для выделения результатов поиска в тексте.



## Классы

| Класс | Описание |
| --- | --- |
| [DocumentHighlighter](../com.groupdocs.search.highlighters/documenthighlighter) | Представляет подсветку результатов поиска, которая выделяет результаты поиска во всем тексте документа. |
| [FragmentHighlighter](../com.groupdocs.search.highlighters/fragmenthighlighter) | Представляет подсветку результатов поиска, которая выделяет результаты поиска в фрагментах текста. |
| [Highlighter](../com.groupdocs.search.highlighters/highlighter) | Представляет базовый класс подсветки результатов поиска. |

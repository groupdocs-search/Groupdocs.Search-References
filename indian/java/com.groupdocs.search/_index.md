पैकेज विभिन्न स्वरूपों के दस्तावेज़ों में टेक्स्ट डेटा को इंडेक्स करने और खोजने के लिए क्लास प्रदान करता है। इस पैकेज में मुख्य क्लास हैं:

Index इंडेक्सिंग और खोज ऑपरेशनों के लिए प्रवेश बिंदु है।

SearchQuery बेस क्लास और ऑब्जेक्ट रूप में सभी प्रकार की खोज क्वेरीज़ के लिए फ़ैक्टरी है।

IndexRepository कई इंडेक्स को संयोजित करने और उन पर सामान्य ऑपरेशनों को करने के लिए कंटेनर क्लास है।

| [Document](../com.groupdocs.search/document) | फ़ाइल सिस्टम, स्ट्रीम या संरचना से इंडेक्स में जोड़े गए दस्तावेज़ों के लिए आधार वर्ग का प्रतिनिधित्व करता है। |
| [DocumentFilter](../com.groupdocs.search/documentfilter) | दस्तावेज़ फ़िल्टरों के लिए आधार वर्ग का प्रतिनिधित्व करता है। |

| [Index](../com.groupdocs.search/index) | दस्तावेज़ों को इंडेक्स करने और उनके माध्यम से खोज करने के लिए मुख्य वर्ग का प्रतिनिधित्व करता है। |
| [IndexRepository](../com.groupdocs.search/indexrepository) | कई इंडेक्सों को संयोजित करने और उन पर सामान्य संचालन करने के लिए एक कंटेनर का प्रतिनिधित्व करता है। |
| [IndexSettings](../com.groupdocs.search/indexsettings) | इंडेक्स सेटिंग्स का प्रतिनिधित्व करता है जो इंडेक्सिंग संचालन को अनुकूलित करने की अनुमति देती हैं। |
| [IndexUpdater](../com.groupdocs.search/indexupdater) | इंडेक्स अपडेटर का प्रतिनिधित्व करता है। |

| [Notification](../com.groupdocs.search/notification) | इंडेक्स को सभी सूचनाओं के लिए आधार वर्ग। |

| [SearchDocumentFilter](../com.groupdocs.search/searchdocumentfilter) | खोज दस्तावेज़ फ़िल्टर बनाने के लिए विधियों को शामिल करता है। |
| [SearchQuery](../com.groupdocs.search/searchquery) | ऑब्जेक्ट रूप में खोज क्वेरी का प्रतिनिधित्व करता है। |

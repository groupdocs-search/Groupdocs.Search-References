पैकेज विभिन्न शब्दकोशों की क्लास प्रदान करता है।



## क्लासेस

| क्लास | विवरण |
| --- | --- |
| [AliasReplacementPair](../com.groupdocs.search.dictionaries/aliasreplacementpair) | एक उपनाम/प्रतिस्थापन जोड़ी का प्रतिनिधित्व करता है। |
| [CharacterReplacementPair](../com.groupdocs.search.dictionaries/characterreplacementpair) | एक अक्षर/प्रतिस्थापन जोड़ी का प्रतिनिधित्व करता है। |
| [DictionaryRepository](../com.groupdocs.search.dictionaries/dictionaryrepository) | इंडेक्स में सभी शब्दकोशों का रिपॉज़िटरी का प्रतिनिधित्व करता है। |
| [EnglishWordFormsProvider](../com.groupdocs.search.dictionaries/englishwordformsprovider) | अंग्रेज़ी शब्द रूप प्रदान करने वाले का प्रतिनिधित्व करता है। |

## इंटरफ़ेस

| इंटरफ़ेस | विवरण |
| --- | --- |
| [AliasDictionary](../com.groupdocs.search.dictionaries/aliasdictionary) | उपनामों के शब्दकोश का इंटरफ़ेस परिभाषित करता है। |
| [Alphabet](../com.groupdocs.search.dictionaries/alphabet) | इंडेक्सिंग के दौरान अक्षर प्रकार का पता लगाने के लिए उपयोग किए जाने वाले अक्षरों के शब्दकोश का इंटरफ़ेस परिभाषित करता है। |
| [CharacterReplacementDictionary](../com.groupdocs.search.dictionaries/characterreplacementdictionary) | इंडेक्सिंग प्रक्रिया के दौरान उपयोग किए जाने वाले अक्षर प्रतिस्थापन शब्दकोश का इंटरफ़ेस परिभाषित करता है। |
| [DictionaryBase](../com.groupdocs.search.dictionaries/dictionarybase) | डिक्शनरी का इंटरफ़ेस परिभाषित करता है। |
| [HomophoneDictionary](../com.groupdocs.search.dictionaries/homophonedictionary) | हेटरोग्राफिक होमोफोन की डिक्शनरी का इंटरफ़ेस परिभाषित करता है। |
| [IWordFormsProvider](../com.groupdocs.search.dictionaries/iwordformsprovider) | शब्द रूप प्रदाता का इंटरफ़ेस परिभाषित करता है। |
| [PasswordDictionary](../com.groupdocs.search.dictionaries/passworddictionary) | दस्तावेज़ पासवर्ड की डिक्शनरी का इंटरफ़ेस परिभाषित करता है। |
| [SpellingCorrector](../com.groupdocs.search.dictionaries/spellingcorrector) | क्वेरी में शब्दों के लिए वर्तनी सुधारक का इंटरफ़ेस परिभाषित करता है। |
| [StopWordDictionary](../com.groupdocs.search.dictionaries/stopworddictionary) | स्टॉप शब्दों की डिक्शनरी का इंटरफ़ेस परिभाषित करता है। |
| [SynonymDictionary](../com.groupdocs.search.dictionaries/synonymdictionary) | समानार्थक शब्दों की डिक्शनरी का इंटरफ़ेस परिभाषित करता है। |

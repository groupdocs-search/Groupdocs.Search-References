पैकेज इवेंट आर्ग्युमेंट्स की क्लास प्रदान करता है।



## क्लासेस

| क्लास | विवरण |
| --- | --- |
| [BaseIndexEventArgs](../com.groupdocs.search.events/baseindexeventargs) | इवेंट तर्कों की बेस क्लास को दर्शाता है। |
| [Event<T>](../com.groupdocs.search.events/event) | इवेंट्स की सदस्यता लेते समय इस क्लास को विरासत में लेने के लिए अभिप्रेत है। |
| [EventHub](../com.groupdocs.search.events/eventhub) | सदस्यता के लिए इंडेक्स घटनाएँ प्रदान करता है। |
| [EventHubBase](../com.groupdocs.search.events/eventhubbase) | इवेंट हब्स के लिए बेस एब्स्ट्रैक्ट क्लास। |
| [FileIndexingEventArgs](../com.groupdocs.search.events/fileindexingeventargs) | दस्तावेज़ अनुक्रमण शुरू होने की घटना के लिए तर्क दर्शाता है। |
| [ImagePreparingEventArgs](../com.groupdocs.search.events/imagepreparingeventargs) | छवि तैयार करने की शुरुआत की घटना के लिए तर्क दर्शाता है। |
| [IndexErrorEventArgs](../com.groupdocs.search.events/indexerroreventargs) | इंडेक्स त्रुटि उत्पन्न होने की घटना के लिए तर्क दर्शाता है। |
| [OperationFinishedEventArgs](../com.groupdocs.search.events/operationfinishedeventargs) | अनुक्रमण ऑपरेशन समाप्त होने की घटना के लिए तर्क दर्शाता है। |
| [OperationProgressEventArgs](../com.groupdocs.search.events/operationprogresseventargs) | अनुक्रमण ऑपरेशन की प्रगति अपडेट होने की घटना के लिए तर्क दर्शाता है। |
| [OptimizationProgressEventArgs](../com.groupdocs.search.events/optimizationprogresseventargs) | अनुक्रमण ऑपरेशन की प्रगति अपडेट होने की घटना के लिए तर्क दर्शाता है। |
| [PasswordRequiredEventArgs](../com.groupdocs.search.events/passwordrequiredeventargs) | जब पासवर्ड द्वारा संरक्षित दस्तावेज़ का अनुक्रमण हो रहा हो, तब होने वाली घटना के लिए तर्क दर्शाता है। |
| [SearchPhaseEventArgs](../com.groupdocs.search.events/searchphaseeventargs) | खोज चरण परिवर्तन घटनाओं के लिए तर्क दर्शाता है। |

| क्लास | विवरण |
| --- | --- |
| [DataExtractedEventArgs](../com.groupdocs.search.scaling.events/dataextractedeventargs) | दस्तावेज़ डेटा निष्कर्षण समाप्त होने की घटना के लिए तर्क दर्शाता है। |
| [DocumentDeletedEventArgs](../com.groupdocs.search.scaling.events/documentdeletedeventargs) | दस्तावेज़ विलोपन समाप्त होने की घटना के लिए तर्क दर्शाता है। |
| [DocumentIndexedEventArgs](../com.groupdocs.search.scaling.events/documentindexedeventargs) | दस्तावेज़ अनुक्रमण समाप्त होने की घटना के लिए तर्क दर्शाता है। |
| [ErrorOccurredEventArgs](../com.groupdocs.search.scaling.events/erroroccurredeventargs) | खोज नेटवर्क के एक नोड में त्रुटि उत्पन्न होने की घटना के लिए तर्क दर्शाता है। |

| [NetworkOptimizationProgressEventArgs](../com.groupdocs.search.scaling.events/networkoptimizationprogresseventargs) | अनुकूलन ऑपरेशन की प्रगति परिवर्तन घटना के लिए तर्क दर्शाता है। |
| [NodeEventHub](../com.groupdocs.search.scaling.events/nodeeventhub) | सदस्यता के लिए नोड घटनाएँ प्रदान करता है। |
| [StatusChangedEventArgs](../com.groupdocs.search.scaling.events/statuschangedeventargs) | खोज नेटवर्क स्थिति परिवर्तन घटना के लिए तर्क दर्शाता है। |

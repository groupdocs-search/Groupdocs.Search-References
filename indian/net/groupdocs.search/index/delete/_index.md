## Delete(string[], UpdateOptions) {#delete_1}

इंडेक्स से इंडेक्स किए गए फ़ाइलों या फ़ोल्डरों को हटाता है। फिर हटाए गए पथों के बिना इंडेक्स को अपडेट करता है। ध्यान दें कि यदि कोई दस्तावेज़ फ़ोल्डर के हिस्से के रूप में इंडेक्स में जोड़ा गया था तो उसे व्यक्तिगत रूप से हटाया नहीं जा सकता।

```csharp
public DeleteResult Delete(string[] paths, UpdateOptions options)
```

| पैरामीटर | प्रकार | विवरण |
| --- | --- | --- |
| paths | String[] | हटाने के लिए फ़ाइलों या फ़ोल्डरों के पथ। |
| विकल्प | UpdateOptions | अपडेट विकल्प। |

### रिटर्न मान

इंडेक्स से फ़ाइलों या फ़ोल्डरों को हटाने के परिणाम का वर्णन करने वाला एक ऑब्जेक्ट।

### उदाहरण

उदाहरण दिखाता है कि कैसे एक इंडेक्स से अनुक्रमित पथों को हटाया जाए।

```csharp
string indexFolder = @"c:\MyIndex\";
string documentsFolder1 = @"c:\MyDocuments\";
string documentsFolder2 = @"c:\MyDocuments2\";

// निर्दिष्ट फ़ोल्डर में एक इंडेक्स बना रहा है
Index index = new Index(indexFolder);

// निर्दिष्ट फ़ोल्डरों से दस्तावेज़ों का अनुक्रमण
index.Add(documentsFolder1);
index.Add(documentsFolder2);

// इंडेक्स से अनुक्रमित पथ प्राप्त करना
string[] indexedPaths1 = index.GetIndexedPaths();

// अनुक्रमित पथों को कंसोल में लिखना
Console.WriteLine("Indexed paths:");
foreach (string path in indexedPaths1)
{
    Console.WriteLine("\t" + path);
}

// इंडेक्स से इंडेक्स पथ को हटाना
DeleteResult deleteResult = index.Delete(new string[] { documentsFolder1 }, new UpdateOptions());

// हटाने के बाद अनुक्रमित पथ प्राप्त करना
string[] indexedPaths2 = index.GetIndexedPaths();
Console.WriteLine("\nDeleted paths: " + deleteResult.SuccessCount);

Console.WriteLine("\nIndexed paths:");
foreach (string path in indexedPaths2)
{
    Console.WriteLine("\t" + path);
}
```

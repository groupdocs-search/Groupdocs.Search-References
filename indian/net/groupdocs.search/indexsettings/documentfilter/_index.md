## IndexSettings.DocumentFilter property

एक दस्तावेज़ फ़िल्टर प्राप्त करता है या सेट करता है। `DocumentFilter` समावेशन लॉजिक पर काम करता है। दस्तावेज़ फ़िल्टर इंस्टेंस बनाने के लिए [`DocumentFilter`](../../../groupdocs.search.options/documentfilter) क्लास का उपयोग करें। डिफ़ॉल्ट मान `null` है, जिसका अर्थ है कि सभी जोड़े गए दस्तावेज़ों को इंडेक्स किया जाता है।

```csharp
public DocumentFilter DocumentFilter { get; set; }
```

### Property Value

दस्तावेज़ फ़िल्टर।

### उदाहरण

उदाहरण दर्शाता है कि दस्तावेज़ फ़िल्टर कैसे सेट करें।

```csharp
string indexFolder = @"c:\MyIndex\";
string documentsFolder = @"c:\MyDocuments\";

// ऐसा फ़िल्टर बनाना जो '.doc', '.docx', '.rtf' एक्सटेंशन वाले दस्तावेज़ों को छोड़ देता है।
IndexSettings settings = new IndexSettings();
DocumentFilter fileExtensionFilter = DocumentFilter.CreateFileExtension(".doc", ".docx", ".rtf"); // Creating file extension filter
DocumentFilter invertedFilter = DocumentFilter.CreateNot(fileExtensionFilter); // Inverting file extension filter
settings.DocumentFilter = invertedFilter;

// निर्दिष्ट फ़ोल्डर में एक इंडेक्स बना रहा है
Index index = new Index(indexFolder, settings);

// दस्तावेज़ों को इंडेक्स किया जा रहा है
index.Add(documentsFolder);

// खोज
SearchResult result = index.Search("Einstein");
```

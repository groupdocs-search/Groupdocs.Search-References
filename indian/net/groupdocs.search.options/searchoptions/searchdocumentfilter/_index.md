## SearchOptions.SearchDocumentFilter property

search document filter को प्राप्त करता है या सेट करता है। `SearchDocumentFilter` समावेशन तर्क पर काम करता है। [`SearchDocumentFilter`](../../searchdocumentfilter) क्लास का उपयोग search document filter के उदाहरण बनाने के लिए करें। डिफ़ॉल्ट मान `null` है, जिसका अर्थ है कि सभी पाए गए दस्तावेज़ लौटाए जाएंगे।

```csharp
public ISearchDocumentFilter SearchDocumentFilter { get; set; }
```

### Property Value

सर्च दस्तावेज़ फ़िल्टर।

### उदाहरण

उदाहरण दर्शाता है कि दस्तावेज़ फ़िल्टर कैसे सेट करें।

```csharp
string indexFolder = @"c:\MyIndex\";
string documentsFolder = @"c:\MyDocuments1\";

// निर्दिष्ट फ़ोल्डर में एक इंडेक्स बना रहा है
Index index = new Index(indexFolder);

// दस्तावेज़ों को इंडेक्स किया जा रहा है
index.Add(documentsFolder);

// एक खोज दस्तावेज़ फ़िल्टर बनाना जो '.doc', '.docx', '.rtf' एक्सटेंशन वाले दस्तावेज़ों को छोड़ देता है।
SearchOptions options = new SearchOptions();
ISearchDocumentFilter fileExtensionFilter = SearchDocumentFilter.CreateFileExtension(".doc", ".docx", ".rtf"); // Creating file extension filter
ISearchDocumentFilter invertedFilter = SearchDocumentFilter.CreateNot(fileExtensionFilter); // Inverting file extension filter
options.SearchDocumentFilter = invertedFilter;

// इंडेक्स में खोज
SearchResult result = index.Search("Einstein", options);
```

## SeparateProcessOptions.UseDotnetToStartProcess property

प्रक्रिया शुरू करने के लिए `dotnet` उपयोग करने का फ़्लैग प्राप्त करता है या सेट करता है। डिफ़ॉल्ट मान `true` है। यदि आप एक स्व‑निहित एप्लिकेशन शुरू करना चाहते हैं तो मान को `false` सेट करें। ध्यान दें कि पुराने .NET Framework पर `dotnet` कभी उपयोग नहीं किया जाता है।

```csharp
public bool UseDotnetToStartProcess { get; set; }
```

### Property Value

`dotnet` का उपयोग करके प्रक्रिया को शुरू करने का फ़्लैग।

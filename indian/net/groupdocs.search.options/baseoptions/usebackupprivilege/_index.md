## BaseOptions.UseBackupPrivilege property

एक मान प्राप्त करता या सेट करता है जो दर्शाता है कि प्रक्रिया को फ़ाइलों और डायरेक्टरीज़ तक पहुँचने के लिए SeBackupPrivilege और FILE_FLAG_BACKUP_SEMANTICS का उपयोग करना चाहिए या नहीं। डिफ़ॉल्ट मान `false` है।

```csharp
public bool UseBackupPrivilege { get; set; }
```

### Property Value

`true` SeBackupPrivilege और FILE_FLAG_BACKUP_SEMANTICS का उपयोग करके विशेषाधिकारयुक्त पहुँच सक्षम करने के लिए; अन्यथा, `false`।

### टिप्पणियाँ

सक्षम होने पर, यह प्रक्रिया को फ़ाइल और डायरेक्टरी सुरक्षा जांचों को बायपास करने की अनुमति देता है, जिससे सामान्यतः ACLs द्वारा प्रतिबंधित संरक्षित संसाधनों तक पहुँच मिलती है — बशर्ते प्रक्रिया के पास उचित विशेषाधिकार हों। यह सुविधा केवल Windows ऑपरेटिंग सिस्टम पर समर्थित है। गैर‑Windows प्लेटफ़ॉर्म पर इस प्रॉपर्टी को सक्षम करने का कोई प्रभाव नहीं होता। ध्यान दें कि इसके लिए प्रक्रिया को प्रशासनिक अधिकारों के साथ चलना आवश्यक है। सावधानी से उपयोग करें, क्योंकि यह संवेदनशील सिस्टम फ़ाइलों और उपयोगकर्ता डेटा तक पहुँच प्रदान कर सकता है।

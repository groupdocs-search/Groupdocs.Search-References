이 패키지는 다양한 형식의 문서에서 텍스트 데이터를 색인하고 검색하기 위한 클래스를 제공합니다. 이 패키지의 주요 클래스는 다음과 같습니다:

Index는 색인 및 검색 작업을 위한 진입점입니다.

SearchQuery는 객체 형태의 모든 유형의 검색 쿼리를 위한 기본 클래스이자 팩토리입니다.

IndexRepository는 여러 색인을 결합하고 공통 작업을 수행하기 위한 컨테이너 클래스입니다.



## 클래스

| 클래스 | 설명 |
| --- | --- |
| [Action](../com.groupdocs.search/action) | 매개변수가 없고 값을 반환하지 않는 메서드를 캡슐화합니다. |
| [Action1<T>](../com.groupdocs.search/action1) | 단일 매개변수를 가지고 반환값이 없는 메서드를 캡슐화합니다. |
| [Action2<T1,T2>](../com.groupdocs.search/action2) | 두 개의 매개변수를 가지고 반환값이 없는 메서드를 캡슐화합니다. |
| [Document](../com.groupdocs.search/document) | 파일 시스템, 스트림 또는 구조에서 인덱스로 추가된 문서의 기본 클래스를 나타냅니다. |
| [DocumentFilter](../com.groupdocs.search/documentfilter) | 문서 필터의 기본 클래스를 나타냅니다. |
| [ExtractedData](../com.groupdocs.search/extracteddata) | 문서에서 검색되어 인덱싱을 위해 준비된 데이터를 나타냅니다. |
| [Extractor](../com.groupdocs.search/extractor) | 후속 빠른 인덱싱 단계와 분리하기 위해 문서에서 사전 데이터 추출을 수행하는 도구를 나타냅니다. |
| [Index](../com.groupdocs.search/index) | 문서를 인덱싱하고 검색하기 위한 주요 클래스를 나타냅니다. |
| [IndexRepository](../com.groupdocs.search/indexrepository) | 여러 인덱스를 결합하고 공통 작업을 수행하기 위한 컨테이너를 나타냅니다. |
| [IndexSettings](../com.groupdocs.search/indexsettings) | 인덱싱 작업을 사용자 정의할 수 있게 하는 인덱스 설정을 나타냅니다. |
| [IndexUpdater](../com.groupdocs.search/indexupdater) | 인덱스 업데이트 프로그램을 나타냅니다. |
| [LicenseRestrictionException](../com.groupdocs.search/licenserestrictionexception) | 라이선스 제한이 발생했을 때 발생하는 예외입니다. |
| [Notification](../com.groupdocs.search/notification) | 인덱스에 대한 모든 알림의 기본 클래스입니다. |
| [PleaseReportException](../com.groupdocs.search/pleasereportexception) | 라이브러리에서 오류가 발생했을 때 발생하는 예외를 나타냅니다. |
| [SearchDocumentFilter](../com.groupdocs.search/searchdocumentfilter) | 검색 문서 필터를 생성하는 메서드를 포함합니다. |
| [SearchQuery](../com.groupdocs.search/searchquery) | 객체 형태의 검색 쿼리를 나타냅니다. |

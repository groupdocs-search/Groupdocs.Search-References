## FileType.ASF field

Advanced Systems Format (ASF)은 주로 미디어 스트림을 저장하고 전송하기 위해 설계된 디지털 멀티미디어 컨테이너입니다. Microsoft Windows Media Video (WMV)는 압축 비디오 형식이며 Microsoft Windows Media Audio (WMA)는 압축 오디오 형식으로, Microsoft에서 개발한 ASF 컨테이너에 추가 메타데이터가 포함됩니다. 이 파일 형식에 대해 자세히 알아보려면 [here](https://wiki.fileformat.com/video/wmv/)를 클릭하세요.

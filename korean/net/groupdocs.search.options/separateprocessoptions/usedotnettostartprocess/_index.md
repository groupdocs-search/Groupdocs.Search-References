## SeparateProcessOptions.UseDotnetToStartProcess property

`dotnet`을 사용하여 프로세스를 시작하는 플래그를 가져오거나 설정합니다. 기본값은 `true`입니다. 자체 포함 애플리케이션을 시작하려면 값을 `false`로 설정하십시오. 오래된 .NET Framework에서는 `dotnet`이 절대 사용되지 않음을 참고하십시오.

```csharp
public bool UseDotnetToStartProcess { get; set; }
```

### Property Value

`dotnet`을 사용하여 프로세스를 시작하는 플래그.

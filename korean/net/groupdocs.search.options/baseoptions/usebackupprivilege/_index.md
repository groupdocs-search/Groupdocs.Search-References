## BaseOptions.UseBackupPrivilege property

프로세스가 파일 및 디렉터리에 접근하기 위해 SeBackupPrivilege와 FILE_FLAG_BACKUP_SEMANTICS를 사용할지 여부를 나타내는 값을 가져오거나 설정합니다. 기본값은 `false`입니다.

```csharp
public bool UseBackupPrivilege { get; set; }
```

### Property Value

`true`는 SeBackupPrivilege와 FILE_FLAG_BACKUP_SEMANTICS를 사용한 특권 접근을 활성화합니다; 그렇지 않으면 `false`입니다.

### 비고

활성화되면 프로세스가 파일 및 디렉터리 보안 검사를 우회하여 일반적으로 ACL에 의해 제한되는 보호된 리소스에 접근할 수 있게 합니다—프로세스가 적절한 특권을 가지고 있는 경우에만 가능합니다. 이 기능은 Windows 운영 체제에서만 지원됩니다. 비 Windows 플랫폼에서는 이 속성을 활성화해도 효과가 없습니다. 이 기능을 사용하려면 프로세스가 관리자 권한으로 실행되어야 함을 유의하십시오. 민감한 시스템 파일 및 사용자 데이터에 접근할 수 있게 될 수 있으므로 주의해서 사용하십시오.

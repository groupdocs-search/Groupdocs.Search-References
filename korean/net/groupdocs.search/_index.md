이 네임스페이스는 다양한 형식의 문서에서 텍스트 데이터를 색인하고 검색하기 위한 클래스를 제공합니다. 이 네임스페이스의 주요 클래스는 다음과 같습니다:

## 클래스

| 클래스 | 설명 |
| --- | --- |
| [ExtractionHost](./extractionhost) | 문서에서 데이터를 별도 프로세스로 추출하는 서비스를 나타냅니다. |
| [Extractor](./extractor) | 후속 빠른 인덱싱 단계와 분리하기 위해 문서에서 사전 데이터 추출을 수행하는 도구를 나타냅니다. |
| [Index](./index) | 문서를 인덱싱하고 검색하는 주요 클래스를 나타냅니다. |
| [IndexRepository](./indexrepository) | 여러 인덱스를 결합하고 공통 작업을 수행하기 위한 컨테이너를 나타냅니다. |
| [IndexSettings](./indexsettings) | 인덱싱 작업을 사용자 지정할 수 있는 인덱스 설정을 나타냅니다. |
| [IndexUpdater](./indexupdater) | 인덱스 업데이트 프로그램을 나타냅니다. 이 클래스는 이전 버전 인덱스의 문서를 재인덱싱합니다. |
| [License](./license) | 라이선스를 적용하기 위한 메서드를 제공합니다. |
| [Metered](./metered) | Metered 라이선스로 제품을 활성화하고 처리된 MB 양을 검색할 수 있는 메서드를 제공합니다. Metered 라이선스에 대한 자세한 내용은 [here](https://purchase.groupdocs.com/faqs/licensing/metered)에서 확인하십시오. |
| [SearchQuery](./searchquery) | 검색 쿼리를 객체 형태로 나타냅니다. |

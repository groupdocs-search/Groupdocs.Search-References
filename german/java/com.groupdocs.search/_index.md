Das Paket stellt Klassen zum Indizieren und Durchsuchen von Textdaten in Dokumenten verschiedener Formate bereit. Die wichtigsten Klassen in diesem Paket sind:

Index ist der Einstiegspunkt für Indexierungs- und Suchvorgänge.

SearchQuery ist die Basisklasse und Fabrik für alle Arten von Suchabfragen in Objektform.

IndexRepository ist eine Containerklasse zum Kombinieren mehrerer Indizes und zum Ausführen gemeinsamer Vorgänge auf ihnen.



## Klassen

| Klasse | Beschreibung |
| --- | --- |
| [Action](../com.groupdocs.search/action) | Kapselt eine Methode, die keine Parameter hat und keinen Wert zurückgibt. |
| [Action1<T>](../com.groupdocs.search/action1) | Kapselt eine Methode, die einen einzelnen Parameter hat und keinen Wert zurückgibt. |
| [Action2<T1,T2>](../com.groupdocs.search/action2) | Kapselt eine Methode, die zwei Parameter hat und keinen Wert zurückgibt. |
| [Document](../com.groupdocs.search/document) | Stellt die Basisklasse für Dokumente dar, die einem Index aus dem Dateisystem, einem Stream oder einer Struktur hinzugefügt werden. |
| [DocumentFilter](../com.groupdocs.search/documentfilter) | Stellt die Basisklasse für Dokumentfilter dar. |
| [ExtractedData](../com.groupdocs.search/extracteddata) | Stellt Daten dar, die aus einem Dokument abgerufen und für die Indizierung vorbereitet wurden. |
| [Extractor](../com.groupdocs.search/extractor) | Stellt ein Werkzeug zur vorläufigen Datenerfassung aus Dokumenten dar, um die Phase der nachfolgenden schnellen Indizierung zu trennen. |
| [Index](../com.groupdocs.search/index) | Stellt die Hauptklasse für die Indizierung von Dokumenten und die Suche darin dar. |
| [IndexRepository](../com.groupdocs.search/indexrepository) | Stellt einen Container dar, der mehrere Indizes kombiniert und gemeinsame Operationen darauf ausführt. |
| [IndexSettings](../com.groupdocs.search/indexsettings) | Stellt die Indexeinstellungen dar, die die Anpassung der Indizierungsoperationen ermöglichen. |
| [IndexUpdater](../com.groupdocs.search/indexupdater) | Stellt einen Index-Aktualisierer dar. |
| [LicenseRestrictionException](../com.groupdocs.search/licenserestrictionexception) | Die Ausnahme, die ausgelöst wird, wenn eine Lizenzbeschränkung greift. |
| [Notification](../com.groupdocs.search/notification) | Die Basisklasse für alle Benachrichtigungen an den Index. |
| [PleaseReportException](../com.groupdocs.search/pleasereportexception) | Stellt die Ausnahme dar, die ausgelöst wird, wenn ein Fehler in der Bibliothek auftritt. |
| [SearchDocumentFilter](../com.groupdocs.search/searchdocumentfilter) | Enthält Methoden zum Erstellen von Suchdokumentfiltern. |
| [SearchQuery](../com.groupdocs.search/searchquery) | Stellt eine Suchabfrage in Objektform dar. |

Das Paket stellt Klassen für Suchergebnisse bereit.



## Klassen

| Klasse | Beschreibung |
| --- | --- |
| [DeleteResult](../com.groupdocs.search.results/deleteresult) | Stellt das Ergebnis der Operation zum Löschen indizierter Dateien oder Ordner aus einem Index dar. |
| [DocumentInfo](../com.groupdocs.search.results/documentinfo) | Stellt einen Deskriptor für ein indiziertes Dokument dar. |
| [FileType](../com.groupdocs.search.results/filetype) | Stellt den Dateityp dar. |
| [FormatFamily](../com.groupdocs.search.results/formatfamily) | Gibt eine Formatfamilie an, die mehrere ähnliche Formate vereint. |
| [FoundDocument](../com.groupdocs.search.results/founddocument) | Stellt ein gefundenes Dokument dar. |
| [FoundDocumentField](../com.groupdocs.search.results/founddocumentfield) | Stellt ein gefundenes Dokumentsfeld dar. |
| [FoundImageFrame](../com.groupdocs.search.results/foundimageframe) | Stellt einen gefundenen Bildrahmen dar. |
| [ImageSearchResult](../com.groupdocs.search.results/imagesearchresult) | Stellt das Ergebnis einer umgekehrten Bildsuche dar. |
| [PathDeleteResult](../com.groupdocs.search.results/pathdeleteresult) | Stellt das Ergebnis der Operation zum Löschen einer indizierten Datei oder eines Ordners aus einem Index dar. |
| [SearchResult](../com.groupdocs.search.results/searchresult) | Stellt ein Suchergebnis dar, das zu einer Suchanfrage passt. |

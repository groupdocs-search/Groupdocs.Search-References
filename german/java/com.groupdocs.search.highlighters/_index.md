Das Paket stellt Hervorhebungen zum Markieren von Suchergebnissen im Text bereit.



## Klassen

| Klasse | Beschreibung |
| --- | --- |
| [DocumentHighlighter](../com.groupdocs.search.highlighters/documenthighlighter) | Stellt einen Suchergebnis-Hervorheber dar, der Suchergebnisse im gesamten Dokumenttext hervorhebt. |
| [FragmentHighlighter](../com.groupdocs.search.highlighters/fragmenthighlighter) | Stellt einen Suchergebnis-Hervorheber dar, der Suchergebnisse in Textfragmenten hervorhebt. |
| [Highlighter](../com.groupdocs.search.highlighters/highlighter) | Stellt die Basisklasse eines Suchergebnis-Hervorhebers dar. |

Der Namespace stellt Klassen für Skalierungsfunktionen bereit.



## Klassen

| Klasse | Beschreibung |
| --- | --- |
| [Indexer](../com.groupdocs.search.scaling/indexer) | Stellt einen Dienst dar, der die Verteilung indizierter Dokumente über Shards des Suchnetzwerks verwaltet. |
| [SearchNetworkNode](../com.groupdocs.search.scaling/searchnetworknode) | Stellt einen Knoten des Suchnetzwerks dar, der Dienste wie extractor, indexer, searcher, shard enthalten kann. |

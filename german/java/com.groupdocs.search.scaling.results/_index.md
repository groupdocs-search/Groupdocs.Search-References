Der Namespace stellt die Klassen für Suchergebnisse im Suchnetzwerk bereit.



## Klassen

| Klasse | Beschreibung |
| --- | --- |
| [NetworkDocumentInfo](../com.groupdocs.search.scaling.results/networkdocumentinfo) | Stellt einen Deskriptor für ein indiziertes Dokument im Suchnetzwerk dar. |
| [NetworkFoundDocument](../com.groupdocs.search.scaling.results/networkfounddocument) | Stellt ein gefundenes Dokument im Suchnetzwerk dar. |
| [NetworkImageSearchResult](../com.groupdocs.search.scaling.results/networkimagesearchresult) | Stellt ein Bildsuchergebnis dar, das zu einem Suchbild passt. |
| [NetworkImageSearchToken](../com.groupdocs.search.scaling.results/networkimagesearchtoken) | Stellt ein Token für die Fortsetzung der Netzwerk‑Chunk‑Bildsuche (Suche nach Seiten) dar. |
| [NetworkSearchResult](../com.groupdocs.search.scaling.results/networksearchresult) | Stellt ein Suchergebnis dar, das zu einer Suchanfrage passt. |
| [NetworkSearchToken](../com.groupdocs.search.scaling.results/networksearchtoken) | Stellt ein Token für die Fortsetzung der Netzwerk‑Chunk‑Suche (Suche nach Seiten) dar. |

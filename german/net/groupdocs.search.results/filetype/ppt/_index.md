## FileType.PPT field

Eine Datei mit der Erweiterung PPT stellt eine PowerPoint‑Datei dar, die aus einer Sammlung von Folien für die Anzeige als Diashow besteht. Sie gibt das von Microsoft PowerPoint 97‑2003 verwendete Binärdateiformat an. Weitere Informationen zu diesem Dateiformat finden Sie [hier](https://wiki.fileformat.com/presentation/ppt/).

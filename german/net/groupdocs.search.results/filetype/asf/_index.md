## FileType.ASF field

Das Advanced Systems Format (ASF) ist ein digitaler Multimedia-Container, der hauptsächlich zum Speichern und Übertragen von Medienströmen entwickelt wurde. Microsoft Windows Media Video (WMV) ist das komprimierte Videoformat und Microsoft Windows Media Audio (WMA) ist das komprimierte Audioformat, zusammen mit zusätzlichen Metadaten im von Microsoft entwickelten ASF-Container. Weitere Informationen zu diesem Dateiformat finden Sie [hier](https://wiki.fileformat.com/video/wmv/).

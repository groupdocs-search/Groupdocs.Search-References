## FileType.XLSB field

Das XLSB-Dateiformat definiert das Excel Binary File Format, das eine Sammlung von Datensätzen und Strukturen ist, die den Inhalt von Excel-Arbeitsmappen festlegen. Weitere Informationen zu diesem Dateiformat finden Sie [here](https://wiki.fileformat.com/specification/spreadsheet/xlsb/).

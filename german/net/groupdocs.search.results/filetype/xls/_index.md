## FileType.XLS field

Dateien mit der XLS-Erweiterung stellen das Excel Binary File Format dar. Solche Dateien können von Microsoft Excel sowie anderen ähnlichen Tabellenkalkulationsprogrammen wie OpenOffice Calc oder Apple Numbers erstellt werden. Weitere Informationen zu diesem Dateiformat finden Sie [here](https://wiki.fileformat.com/specification/spreadsheet/xls/).

## IndexSettings.Logger property

Ruft einen Logger ab oder legt ihn fest, der zum Protokollieren von Ereignissen und Fehlern im Index verwendet wird. Hinweis: Der Logger wird nicht gespeichert und muss jedes Mal erstellt und zugewiesen werden, wenn der Index erstellt oder geladen wird.

```csharp
public ILogger Logger { get; set; }
```

### Property Value

Ein Logger, der zum Protokollieren von Ereignissen und Fehlern im Index verwendet wird.

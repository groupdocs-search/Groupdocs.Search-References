## IndexSettings.SearchThreads property

Ruft die Anzahl der für die Suche verwendeten Threads ab oder legt sie fest. Der Standardwert ist Default, was bedeutet, dass die Suche mit einer Thread‑Anzahl durchgeführt wird, die der Anzahl der Prozessorkerne entspricht.

```csharp
public NumberOfThreads SearchThreads { get; set; }
```

### Property Value

Die Anzahl der für die Suche verwendeten Threads.

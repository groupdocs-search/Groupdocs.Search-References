Der Namespace stellt Klassen zum Indexieren und Durchsuchen von Textdaten in Dokumenten verschiedener Formate bereit. Die wichtigsten Klassen in diesem Namespace sind:

## Klassen

| Klasse | Beschreibung |
| --- | --- |
| [ExtractionHost](./extractionhost) | Stellt einen Dienst zum Extrahieren von Daten aus Dokumenten in einem separaten Prozess dar. |
| [Extractor](./extractor) | Stellt ein Werkzeug für die vorläufige Datenerfassung aus Dokumenten bereit, um die Phase des nachfolgenden schnellen Indexierens zu trennen. |
| [Index](./index) | Stellt die Hauptklasse zum Indexieren von Dokumenten und Durchsuchen dieser dar. |
| [IndexRepository](./indexrepository) | Stellt einen Container zum Kombinieren mehrerer Indizes und zum Ausführen gemeinsamer Operationen auf ihnen dar. |
| [IndexSettings](./indexsettings) | Stellt die Indexeinstellungen dar, die die Anpassung der Indexierungsvorgänge ermöglichen. |
| [IndexUpdater](./indexupdater) | Stellt einen Index-Aktualisierer dar. Diese Klasse führt das Reindizieren von Dokumenten in einem Index einer alten Version durch. |
| [License](./license) | Bietet Methoden zum Anwenden einer Lizenz. |
| [Metered](./metered) | Bietet Methoden, die es ermöglichen, das Produkt mit einer nutzungsbasierten Lizenz zu aktivieren und die verarbeiteten MB-Mengen abzurufen. Weitere Informationen zu nutzungsbasierten Lizenzen finden Sie [hier](https://purchase.groupdocs.com/faqs/licensing/metered). |
| [SearchQuery](./searchquery) | Stellt eine Suchanfrage in Objektform dar. |

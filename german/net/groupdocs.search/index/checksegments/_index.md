## Index.CheckSegments method

Überprüft den Index auf beschädigte Segmentdateien auf der Festplatte. Die Methode repariert die Indexfunktionalität bei beschädigten Segmenten, wenn *fixIndexFunctionality* wahr ist; andernfalls wird nicht repariert.

```csharp
public void CheckSegments(bool fixIndexFunctionality)
```

## BaseOptions.UseRawTextExtraction property

Liest oder setzt einen Wert, der angibt, ob der Rohmodus für die Textextraktion, falls möglich, verwendet wird. Der Standardwert ist `false`. Der Rohmodus kann die Indizierungsgeschwindigkeit erheblich steigern, aber der Normalmodus verbessert die Formatierung des extrahierten Textes.

```csharp
public bool UseRawTextExtraction { get; set; }
```

### Property Value

Ein Wert, der angibt, ob der Rohmodus für die Textextraktion, falls möglich, verwendet wird.

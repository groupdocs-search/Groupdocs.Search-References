## BaseOptions.Encoding property

Liest oder setzt die Kodierung, die zum Extrahieren von Text aus Textdokumenten verwendet wird. Der Standardwert ist `null`, was bedeutet, dass die Standardkodierung UTF-8 verwendet wird. Ist AutoDetectEncoding `true`, wird dieser Wert als Standardkodierung verwendet.

```csharp
public string Encoding { get; set; }
```

### Property Value

Die Kodierung, die zum Extrahieren von Text aus Textdokumenten verwendet wird.

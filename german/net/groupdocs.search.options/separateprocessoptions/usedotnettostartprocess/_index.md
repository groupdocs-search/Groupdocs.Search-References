## SeparateProcessOptions.UseDotnetToStartProcess property

Liefert oder setzt das Flag für die Verwendung von `dotnet` zum Starten des Prozesses. Der Standardwert ist `true`. Setzen Sie den Wert auf `false`, wenn Sie eine eigenständige Anwendung starten möchten. Beachten Sie, dass `dotnet` beim Starten des alten .NET Frameworks niemals verwendet wird.

```csharp
public bool UseDotnetToStartProcess { get; set; }
```

### Property Value

Das Flag für die Verwendung von `dotnet` zum Starten des Prozesses.

## SeparateProcessOptions.ExtractInSeparateProcess property

Liefert oder setzt einen Wert, der angibt, ob ein separater Prozess zum Extrahieren von Daten aus Dokumenten verwendet wird. Der Standardwert ist `false`. Wenn diese Option aktiviert ist, wird die Datener extraction in einem separaten Prozess nur in einem Thread durchgeführt. Die angegebene Anzahl von Threads wird beim Extrahieren in einem separaten Prozess ignoriert.

```csharp
public bool ExtractInSeparateProcess { get; set; }
```

### Property Value

Ein Wert, der angibt, ob ein separater Prozess zum Extrahieren von Daten aus Dokumenten verwendet wird.

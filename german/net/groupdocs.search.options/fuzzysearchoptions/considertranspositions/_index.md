## FuzzySearchOptions.ConsiderTranspositions property

Ruft den Wert ab oder legt ihn fest, der angibt, ob der Fuzzy-Search-Algorithmus die Vertauschung zweier benachbarter Zeichen als einen einzigen Fehler berücksichtigen muss. Der Standardwert ist `true`.

```csharp
public bool ConsiderTranspositions { get; set; }
```

### Property Value

`true`, wenn der Fuzzy‑Suchalgorithmus Vertauschungen berücksichtigt; andernfalls `false`.

## TextOptions.AdditionalFields property

Liest oder setzt die zusätzlichen Dokumentfelder, die für die Indizierung verwendet wurden. Der Standardwert ist `null`. Hinweis: Dieser Wert wird nur verwendet, wenn der Dokumenttext nicht im Index gespeichert wurde.

```csharp
public DocumentField[] AdditionalFields { get; set; }
```

### Property Value

Die zusätzlichen Dokumentfelder, die für die Indizierung verwendet wurden.

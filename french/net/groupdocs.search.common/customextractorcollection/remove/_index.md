## CustomExtractorCollection.Remove method

Supprime un extracteur de la collection.

```csharp
public bool Remove(IFieldExtractor extractor)
```

| Paramètre | Type | Description |
| --- | --- | --- |
| extracteur | IFieldExtractor | L'extracteur à supprimer de la collection. |

### Valeur de retour

`true` si *extractor* a été supprimé avec succès de la collection ; sinon, `false`. Cette méthode renvoie également `false` si *extractor* n'est pas trouvé dans la collection d'origine.

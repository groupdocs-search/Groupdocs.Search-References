L'espace de noms fournit des classes pour l'indexation et la recherche de données textuelles dans des documents de différents formats. Les principales classes de cet espace de noms sont :

## Classes

| Classe | Description |
| --- | --- |
| [ExtractionHost](./extractionhost) | Représente un service d'extraction de données à partir de documents dans un processus séparé. |
| [Extractor](./extractor) | Représente un outil d'extraction préliminaire de données à partir de documents afin de séparer l'étape d'indexation rapide ultérieure. |
| [Index](./index) | Représente la classe principale pour l'indexation de documents et la recherche parmi ceux-ci. |
| [IndexRepository](./indexrepository) | Représente un conteneur permettant de combiner plusieurs index et d'exécuter des opérations communes sur ceux-ci. |
| [IndexSettings](./indexsettings) | Représente les paramètres d'index qui permettent de personnaliser les opérations d'indexation. |
| [IndexUpdater](./indexupdater) | Représente une mise à jour d'index. Cette classe effectue le réindexage des documents dans un index d'une version antérieure. |
| [License](./license) | Fournit des méthodes pour appliquer la licence. |
| [Metered](./metered) | Fournit des méthodes qui permettent d'activer le produit avec une licence à consommation et de récupérer la quantité de Mo traités. En savoir plus sur les licences à consommation [ici](https://purchase.groupdocs.com/faqs/licensing/metered). |
| [SearchQuery](./searchquery) | Représente une requête de recherche sous forme d'objet. |

## IndexSettings.SearchThreads property

Obtient ou définit le nombre de threads utilisés pour la recherche. La valeur par défaut est Default, ce qui signifie que la recherche sera effectuée en utilisant un nombre de threads égal au nombre de cœurs du processeur.

```csharp
public NumberOfThreads SearchThreads { get; set; }
```

### Property Value

Le nombre de threads utilisés pour la recherche.

## IndexSettings.Logger property

Obtient ou définit un journaliseur utilisé pour consigner les événements et les erreurs dans l'index. Notez que le journaliseur n'est pas sauvegardé et doit être créé et assigné chaque fois que l'index est créé ou chargé.

```csharp
public ILogger Logger { get; set; }
```

### Property Value

Un logger utilisé pour consigner les événements et les erreurs dans l'index.

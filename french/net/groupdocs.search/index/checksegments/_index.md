## Index.CheckSegments method

Vérifie l'index à la recherche de fichiers de segments endommagés sur le disque. La méthode répare la fonctionnalité de l'index en présence de segments endommagés si *fixIndexFunctionality* est vrai; sinon, elle ne répare pas.

```csharp
public void CheckSegments(bool fixIndexFunctionality)
```

| Paramètre | Type | Description |
| --- | --- | --- |
| fixIndexFunctionality | Boolean | Le drapeau de correction de la fonctionnalité d'index. |

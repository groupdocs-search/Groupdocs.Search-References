## IndexUpdater.CanUpdateVersion method

Vérifie si un index dans le répertoire spécifié peut être mis à jour vers la dernière version.

```csharp
public bool CanUpdateVersion(string indexPath)
```

| Paramètre | Type | Description |
| --- | --- | --- |
| indexPath | String | Le chemin du répertoire d'index. |

### Valeur de retour

`true` si un index dans le répertoire spécifié peut être mis à jour vers la dernière version; sinon `false`.

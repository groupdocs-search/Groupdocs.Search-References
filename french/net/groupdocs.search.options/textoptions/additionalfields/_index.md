## TextOptions.AdditionalFields property

Obtient ou définit les champs de document supplémentaires qui ont été utilisés pour l'indexation. La valeur par défaut est `null`. Notez que cette valeur n'est utilisée que si le texte du document n'a pas été enregistré dans l'index.

```csharp
public DocumentField[] AdditionalFields { get; set; }
```

### Property Value

Les champs de document supplémentaires qui ont été utilisés pour l'indexation.

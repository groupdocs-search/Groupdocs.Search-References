## TextOptions.CustomExtractor property

Obtient ou définit l'extracteur de texte personnalisé qui a été utilisé pour l'indexation. La valeur par défaut est `null`. Notez que cette valeur n'est utilisée que si le texte du document n'a pas été enregistré dans l'index.

```csharp
public IFieldExtractor CustomExtractor { get; set; }
```

### Property Value

L'extracteur de texte personnalisé qui a été utilisé pour l'indexation.

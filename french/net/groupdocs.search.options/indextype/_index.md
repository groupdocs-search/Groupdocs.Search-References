## IndexType enumeration

Spécifie un type d'index.

```csharp
public enum IndexType
```

### Values

| Nom | Value | Description |
| --- | --- | --- |
| NormalIndex | `0` | Index normal avec les métadonnées et le contenu des documents, qui prend en charge toutes les fonctionnalités de recherche. |
| MetadataIndex | `1` | Index contenant uniquement les métadonnées des documents, sans le contenu. |
| CompactIndex | `2` | Type d'index qui occupe beaucoup moins d'espace disque mais ne prend pas en charge la recherche de phrases et les fonctionnalités de recherche par intervalle de dates. |

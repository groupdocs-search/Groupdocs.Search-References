## DateFormatCollection.Remove method

Supprime la première occurrence d'un élément spécifique de la collection.

```csharp
public bool Remove(DateFormat item)
```

| Paramètre | Type | Description |
| --- | --- | --- |
| item | DateFormat | L'élément à supprimer de la collection. |

### Valeur de retour

`true` si l'élément a été supprimé avec succès de la collection ; sinon, `false`. Cette méthode renvoie également `false` si l'élément n'est pas trouvé dans la collection.

## SpellingCorrectorOptions class

Fournit des options pour le correcteur orthographique.

```csharp
public class SpellingCorrectorOptions
```

## Propriétés

| Nom | Description |
| --- | --- |
| [ConsiderTranspositions](../../groupdocs.search.options/spellingcorrectoroptions/considertranspositions) { get; set; } | Obtient ou définit une valeur indiquant si l'algorithme doit considérer la transposition de deux caractères adjacents comme une seule erreur. La valeur par défaut est `true`. |
| [Enabled](../../groupdocs.search.options/spellingcorrectoroptions/enabled) { get; set; } | Obtient ou définit une valeur indiquant si le correcteur orthographique est activé. La valeur par défaut est `false`. |
| [MaxMistakeCount](../../groupdocs.search.options/spellingcorrectoroptions/maxmistakecount) { get; set; } | Obtient ou définit le nombre maximal d'erreurs. La valeur par défaut est `2`. |
| [OnlyBestResults](../../groupdocs.search.options/spellingcorrectoroptions/onlybestresults) { get; set; } | Obtient ou définit une valeur indiquant si seuls les meilleurs résultats seront renvoyés. La valeur par défaut est `false`. |
| [OnlyBestResultsRange](../../groupdocs.search.options/spellingcorrectoroptions/onlybestresultsrange) { get; set; } | Obtient ou définit le dépassement maximal du nombre minimum d'erreurs qui sont trouvées. La valeur par défaut est `0`. |

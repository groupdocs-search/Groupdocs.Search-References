## SeparateProcessOptions.ExtractInSeparateProcess property

Obtient ou définit une valeur indiquant si un processus séparé est utilisé pour extraire les données des documents. La valeur par défaut est `false`. Lorsque cette option est activée, l'extraction des données est effectuée dans un processus séparé avec un seul thread. Le nombre de threads spécifié est ignoré lors de l'extraction dans un processus séparé.

```csharp
public bool ExtractInSeparateProcess { get; set; }
```

### Property Value

Une valeur indiquant si un processus séparé est utilisé pour extraire les données des documents.

## SeparateProcessOptions.UseDotnetToStartProcess property

Obtient ou définit le drapeau d'utilisation de `dotnet` pour démarrer le processus. La valeur par défaut est `true`. Définissez la valeur sur `false` si vous souhaitez démarrer une application autonome. Notez que `dotnet` n'est jamais utilisé pour démarrer sur l'ancienne version du .NET Framework.

```csharp
public bool UseDotnetToStartProcess { get; set; }
```

### Property Value

Le drapeau d'utilisation de `dotnet` pour démarrer le processus.

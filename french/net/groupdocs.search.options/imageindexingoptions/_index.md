## ImageIndexingOptions class

Fournit des options d'indexation d'images pour la recherche d'images inversée.

```csharp
public class ImageIndexingOptions
```

## Propriétés

| Nom | Description |
| --- | --- |
| [EnabledForContainerItemImages](../../groupdocs.search.options/imageindexingoptions/enabledforcontaineritemimages) { get; set; } | Obtient ou définit une valeur indiquant s'il faut indexer les images qui sont des éléments d'un conteneur (par exemple, des images dans une archive ZIP). La valeur par défaut est `false`. |
| [EnabledForEmbeddedImages](../../groupdocs.search.options/imageindexingoptions/enabledforembeddedimages) { get; set; } | Obtient ou définit une valeur indiquant s'il faut indexer les images intégrées (par exemple, des images dans un document DOCX). La valeur par défaut est `false`. |
| [EnabledForSeparateImages](../../groupdocs.search.options/imageindexingoptions/enabledforseparateimages) { get; set; } | Obtient ou définit une valeur indiquant s'il faut indexer des fichiers image séparés. La valeur par défaut est `false`. |

## BaseOptions.UseRawTextExtraction property

Obtient ou définit une valeur indiquant si le mode brut est utilisé pour l'extraction de texte lorsque cela est possible. La valeur par défaut est `false`. Le mode brut peut augmenter considérablement la vitesse d'indexation, mais le mode normal améliore le formatage du texte extrait.

```csharp
public bool UseRawTextExtraction { get; set; }
```

### Property Value

Une valeur indiquant si le mode brut est utilisé pour l'extraction de texte si possible.

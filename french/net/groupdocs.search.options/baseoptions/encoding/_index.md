## BaseOptions.Encoding property

Obtient ou définit l'encodage utilisé pour extraire le texte des documents texte. La valeur par défaut est `null`, ce qui signifie que l'encodage par défaut UTF-8 est utilisé. Si AutoDetectEncoding est `true`, alors cette valeur est utilisée comme encodage par défaut.

```csharp
public string Encoding { get; set; }
```

### Property Value

Le codage utilisé pour extraire le texte des documents texte.

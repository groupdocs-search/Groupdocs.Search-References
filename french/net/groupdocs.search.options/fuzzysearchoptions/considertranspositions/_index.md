## FuzzySearchOptions.ConsiderTranspositions property

Obtient ou définit une valeur indiquant si l'algorithme de recherche floue doit considérer la transposition de deux caractères adjacents comme une seule erreur. La valeur par défaut est `true`.

```csharp
public bool ConsiderTranspositions { get; set; }
```

### Property Value

`true` si l'algorithme de recherche floue considère les transpositions ; sinon `false`.

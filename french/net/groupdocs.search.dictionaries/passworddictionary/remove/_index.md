## PasswordDictionary.Remove method

Supprime le mot de passe du document spécifié du dictionnaire.

```csharp
public bool Remove(string key)
```

| Paramètre | Type | Description |
| --- | --- | --- |
| clé | String | Le chemin complet du fichier ou une clé de document. |

### Valeur de retour

`true` si le mot de passe a été supprimé avec succès ; sinon, `false`. Cette méthode renvoie également `false` si *key* n'a pas été trouvé dans le dictionnaire.

## FileType.OST field

Les fichiers OST ou Offline Storage Files représentent les données de la boîte aux lettres de l'utilisateur en mode hors ligne sur la machine locale lors de l'enregistrement avec Exchange Server à l'aide de Microsoft Outlook. En savoir plus sur ce format de fichier [ici](https://wiki.fileformat.com/email/ost/).

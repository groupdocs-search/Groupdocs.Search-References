Le package fournit des classes pour l'indexation et la recherche de données textuelles dans des documents de différents formats. Les principales classes de ce package sont :

Index est le point d'entrée pour l'indexation et les opérations de recherche.

SearchQuery est la classe de base et la fabrique pour tous les types de requêtes de recherche sous forme d'objet.

IndexRepository est une classe conteneur pour combiner plusieurs index et effectuer des opérations communes sur ceux-ci.

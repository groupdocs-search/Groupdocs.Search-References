توفر الحزمة فئات لفهرسة والبحث عن بيانات النص في المستندات ذات الصيغ المختلفة. الفئات الرئيسية في هذه الحزمة هي:

Index هو نقطة الدخول لعمليات الفهرسة والبحث.

SearchQuery هو الفئة الأساسية والمصنع لجميع أنواع استعلامات البحث في شكل كائن.

IndexRepository هو فئة حاوية لدمج فهارس متعددة وإجراء عمليات شائعة عليها.



## الفئات

| الفئة | الوصف |
| --- | --- |
| [Action](../com.groupdocs.search/action) | يحتوي على طريقة لا تملك أي معاملات ولا تُرجع قيمة. |
| [Action1<T>](../com.groupdocs.search/action1) | يُغلف طريقة لها معلمة واحدة ولا تُعيد قيمة. |
| [Action2<T1,T2>](../com.groupdocs.search/action2) | يُغلف طريقة لها معلمتين ولا تُعيد قيمة. |
| [Document](../com.groupdocs.search/document) | يمثل الفئة الأساسية للمستندات التي تُضاف إلى الفهرس من نظام الملفات أو التدفق أو الهيكل. |
| [DocumentFilter](../com.groupdocs.search/documentfilter) | يمثل الفئة الأساسية لمرشحات المستندات. |
| [ExtractedData](../com.groupdocs.search/extracteddata) | يمثل البيانات المستخرجة من مستند ومُعدة للفهرسة. |
| [Extractor](../com.groupdocs.search/extractor) | يمثل أداة لاستخراج البيانات الأولية من المستندات لفصل مرحلة الفهرسة السريعة اللاحقة. |
| [Index](../com.groupdocs.search/index) | يمثل الفئة الرئيسية لفهرسة المستندات والبحث فيها. |
| [IndexRepository](../com.groupdocs.search/indexrepository) | يمثل حاوية لدمج فهارس متعددة وإجراء عمليات شائعة عليها. |
| [IndexSettings](../com.groupdocs.search/indexsettings) | يمثل إعدادات الفهرس التي تسمح بتخصيص عمليات الفهرسة. |
| [IndexUpdater](../com.groupdocs.search/indexupdater) | يمثل مُحدّث الفهرس. |
| [LicenseRestrictionException](../com.groupdocs.search/licenserestrictionexception) | الاستثناء الذي يُرمى عندما يتم تفعيل قيد الترخيص. |
| [Notification](../com.groupdocs.search/notification) | الفئة الأساسية لجميع الإشعارات إلى الفهرس. |
| [PleaseReportException](../com.groupdocs.search/pleasereportexception) | يمثل الاستثناء الذي يُرمى عندما يحدث خطأ في المكتبة. |
| [SearchDocumentFilter](../com.groupdocs.search/searchdocumentfilter) | يحتوي على طرق لإنشاء مرشحات مستندات البحث. |
| [SearchQuery](../com.groupdocs.search/searchquery) | يمثل استعلام بحث في شكل كائن. |

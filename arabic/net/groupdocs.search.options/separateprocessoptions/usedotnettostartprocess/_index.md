## SeparateProcessOptions.UseDotnetToStartProcess property

يحصل أو يضبط علامة استخدام `dotnet` لبدء العملية. القيمة الافتراضية هي `true`. اضبط القيمة إلى `false` إذا كنت تريد تشغيل تطبيق مستقل. لاحظ أن `dotnet` لا يُستخدم أبداً للبدء على إطار .NET Framework القديم.

public bool UseDotnetToStartProcess { get; set; }

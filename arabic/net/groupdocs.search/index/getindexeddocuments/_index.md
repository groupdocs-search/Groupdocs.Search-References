## Index.GetIndexedDocuments method

يحصل على مصفوفة من جميع المستندات المفهرسة.

```csharp
public DocumentInfo[] GetIndexedDocuments()
```

### قيمة الإرجاع

مصفوفة تحتوي على جميع المستندات المفهرسة.

### أمثلة

يوضح المثال كيفية الحصول على قائمة بالمستندات المفهرسة من فهرس.

```csharp
string indexFolder = @"c:\MyIndex\";
string documentsFolder = @"c:\MyDocuments\";
 
// إنشاء فهرس في المجلد المحدد
Index index = new Index(indexFolder);
 
// فهرسة المستندات من المجلد المحدد
index.Add(documentsFolder);
 
// الحصول على قائمة المستندات المفهرسة
DocumentInfo[] documents = index.GetIndexedDocuments();
```

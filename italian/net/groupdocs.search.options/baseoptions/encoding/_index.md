## BaseOptions.Encoding property

Ottiene o imposta la codifica usata per estrarre il testo dai documenti di testo. Il valore predefinito è `null`, il che significa che viene usata la codifica predefinita UTF-8. Se AutoDetectEncoding è `true` allora questo valore è usato come codifica predefinita.

```csharp
public string Encoding { get; set; }
```

### Property Value

La codifica utilizzata per estrarre il testo dai documenti di testo.

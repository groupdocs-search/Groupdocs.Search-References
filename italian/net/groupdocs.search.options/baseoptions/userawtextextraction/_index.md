## BaseOptions.UseRawTextExtraction property

Ottiene o imposta un valore che indica se utilizzare la modalità grezza per l'estrazione del testo, se possibile. Il valore predefinito è `false`. La modalità grezza può aumentare notevolmente la velocità di indicizzazione, ma la modalità normale migliora la formattazione del testo estratto.

```csharp
public bool UseRawTextExtraction { get; set; }
```

### Property Value

Un valore che indica se la modalità grezza è utilizzata per l'estrazione del testo, se possibile.

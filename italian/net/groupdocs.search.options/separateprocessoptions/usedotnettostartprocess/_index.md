## SeparateProcessOptions.UseDotnetToStartProcess property

Ottiene o imposta il flag per l'uso di `dotnet` per avviare il processo. Il valore predefinito è `true`. Imposta il valore su `false` se desideri avviare un'applicazione autonoma. Nota che `dotnet` non viene mai utilizzato per avviare sul vecchio .NET Framework.

```csharp
public bool UseDotnetToStartProcess { get; set; }
```

### Property Value

Il flag per l'uso di `dotnet` per avviare il processo.

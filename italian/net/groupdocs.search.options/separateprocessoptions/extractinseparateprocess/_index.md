## SeparateProcessOptions.ExtractInSeparateProcess property

Ottiene o imposta un valore che indica se un processo separato è utilizzato per estrarre dati dai documenti. Il valore predefinito è `false`. Quando questa opzione è abilitata, l'estrazione dei dati viene eseguita in un processo separato con un solo thread. Il numero specificato di thread viene ignorato durante l'estrazione in un processo separato.

```csharp
public bool ExtractInSeparateProcess { get; set; }
```

### Property Value

Un valore che indica se un processo separato viene utilizzato per estrarre dati dai documenti.

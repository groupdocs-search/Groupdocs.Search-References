## FileType.BMP field

I file con estensione .BMP rappresentano file di immagini bitmap utilizzati per memorizzare immagini digitali bitmap. Queste immagini sono indipendenti dall'adattatore grafico e sono anche chiamate formato file device independent bitmap (DIB).

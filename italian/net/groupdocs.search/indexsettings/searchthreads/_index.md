## IndexSettings.SearchThreads property

Ottiene o imposta il numero di thread utilizzati per la ricerca. Il valore predefinito è Default, il che significa che la ricerca verrà eseguita usando un numero di thread pari al numero di core del processore.

public NumberOfThreads SearchThreads { get; set; }

Il namespace fornisce classi per l'indicizzazione e la ricerca di dati testuali nei documenti di diversi formati. Le classi principali in questo namespace sono:

## Classi

| Classe | Descrizione |
| --- | --- |
| [ExtractionHost](./extractionhost) | Rappresenta un servizio per estrarre dati dai documenti in un processo separato. |
| [Extractor](./extractor) | Rappresenta uno strumento per l'estrazione preliminare dei dati dai documenti, al fine di separare la fase di indicizzazione rapida successiva. |
| [Index](./index) | Rappresenta la classe principale per indicizzare i documenti e cercarli. |
| [IndexRepository](./indexrepository) | Rappresenta un contenitore per combinare più indici ed eseguire operazioni comuni su di essi. |
| [IndexSettings](./indexsettings) | Rappresenta le impostazioni dell'indice che consentono di personalizzare le operazioni di indicizzazione. |
| [IndexUpdater](./indexupdater) | Rappresenta un aggiornatore di indice. Questa classe esegue la reindicizzazione dei documenti in un indice di una versione precedente. |
| [License](./license) | Fornisce metodi per applicare la licenza. |
| [Metered](./metered) | Fornisce metodi che consentono di attivare il prodotto con licenza a consumo e recuperare la quantità di MB elaborati. Scopri di più sulle licenze a consumo [qui](https://purchase.groupdocs.com/faqs/licensing/metered). |
| [SearchQuery](./searchquery) | Rappresenta una query di ricerca in forma di oggetto. |

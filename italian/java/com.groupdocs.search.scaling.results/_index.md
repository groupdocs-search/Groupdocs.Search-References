Lo spazio dei nomi fornisce le classi di risultati di ricerca nella rete di ricerca.



## Classi

| Classe | Descrizione |
| --- | --- |
| [NetworkDocumentInfo](../com.groupdocs.search.scaling.results/networkdocumentinfo) | Rappresenta un descrittore per un documento indicizzato nella rete di ricerca. |
| [NetworkFoundDocument](../com.groupdocs.search.scaling.results/networkfounddocument) | Rappresenta un documento trovato nella rete di ricerca. |
| [NetworkImageSearchResult](../com.groupdocs.search.scaling.results/networkimagesearchresult) | Rappresenta un risultato di ricerca immagine corrispondente a un'immagine di ricerca. |
| [NetworkImageSearchToken](../com.groupdocs.search.scaling.results/networkimagesearchtoken) | Rappresenta un token per la continuazione della ricerca di immagini a blocchi nella rete (ricerca per pagine). |
| [NetworkSearchResult](../com.groupdocs.search.scaling.results/networksearchresult) | Rappresenta un risultato di ricerca corrispondente a una query di ricerca. |
| [NetworkSearchToken](../com.groupdocs.search.scaling.results/networksearchtoken) | Rappresenta un token per la continuazione della ricerca a blocchi nella rete (ricerca per pagine). |

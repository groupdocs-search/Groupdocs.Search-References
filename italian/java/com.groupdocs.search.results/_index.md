Il pacchetto fornisce classi di risultati di ricerca.



## Classi

| Classe | Descrizione |
| --- | --- |
| [DeleteResult](../com.groupdocs.search.results/deleteresult) | Rappresenta il risultato dell'operazione di eliminazione di file o cartelle indicizzati da un indice. |
| [DocumentInfo](../com.groupdocs.search.results/documentinfo) | Rappresenta un descrittore per un documento indicizzato. |
| [FileType](../com.groupdocs.search.results/filetype) | Rappresenta il tipo di file. |
| [FormatFamily](../com.groupdocs.search.results/formatfamily) | Specifica una famiglia di formati che unisce diversi formati simili. |
| [FoundDocument](../com.groupdocs.search.results/founddocument) | Rappresenta un documento trovato. |
| [FoundDocumentField](../com.groupdocs.search.results/founddocumentfield) | Rappresenta un campo di documento trovato. |
| [FoundImageFrame](../com.groupdocs.search.results/foundimageframe) | Rappresenta un fotogramma immagine trovato. |
| [ImageSearchResult](../com.groupdocs.search.results/imagesearchresult) | Rappresenta il risultato di una ricerca inversa di immagini. |
| [PathDeleteResult](../com.groupdocs.search.results/pathdeleteresult) | Rappresenta il risultato dell'operazione di eliminazione di un file o cartella indicizzati da un indice. |
| [SearchResult](../com.groupdocs.search.results/searchresult) | Rappresenta un risultato di ricerca corrispondente a una query di ricerca. |

Il pacchetto fornisce classi per l'indicizzazione e la ricerca di dati testuali nei documenti di diversi formati. Le classi principali in questo pacchetto sono:

Index è il punto di ingresso per le operazioni di indicizzazione e ricerca.

SearchQuery è la classe base e la factory per tutti i tipi di query di ricerca in forma di oggetto.

IndexRepository è una classe contenitore per combinare più indici ed eseguire operazioni comuni su di essi.
